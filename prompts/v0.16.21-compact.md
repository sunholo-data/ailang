# AILANG v0.16.21 compact syntax sheet

AILANG is pure functional with Hindley-Milner inference and effect types. No loops, classes or mutation: use recursion, `match` and immutable `let`. Output raw code only (no markdown fences); line 1 is `module path/name`. Full reference: `ailang prompt`.

## Program

```ailang
module myapp/main
import std/io (println)
import std/list (map, filter, foldl)

pure func double(x: int) -> int
  requires { x >= 0 }
  ensures { result >= x }
  tests [(0, 0), (3, 6)]
{
  x * 2
}

export func main() -> () ! {IO @limit=5} {
  let xs = [1, 2, 3]
  let total = foldl(\acc x. acc + x, 0, xs)
  println("total=${show(total)} d=${show(double(4))}")
}
```

- Block body `func f() -> T ! {E} { ... }`: one `let` per line, no `in`. Expression body `= expr` (`let x = a in b`): no `;`. Never write `= { ... }`.
- Effects follow the return type: `! {IO, FS, Net}`. `pure func` means `! {}`. A budget caps calls: `! {IO @limit=5}`.
- Run: `ailang run --entry main --caps IO,FS file.ail` (flags go BEFORE the filename).
- Entry modules (`export func main`) get `println`, `show`, `Option`/`Some`/`None`, `Result`/`Ok`/`Err` for free. Library modules import them: `import std/option (Option, Some, None)`, `import std/result (Result, Ok, Err)`.

## Types and data

- Types: `int float string bool ()`, `[a]`, `(a, b)`, `{x: int, y: string}`, open record `{x: int | r}`, `Option[a]`, `Result[a, e]`, `a -> b`.
- `type Shape = Circle(float) | Rect(float, float) deriving (Eq)`; `type P = {x: int, y: int} deriving (Eq)` (anonymous records have no `==`).
- Records: `{x: 1, y: 2}`, update `{p | x: 5}`. Lists: `[1, 2]`, `x :: xs`.
- Strings: `"${a}${b}"` interpolation, or `concat([a, b])` from `std/string`.

## Control flow

```ailang
pure func area(s: Shape) -> float =
  match s {
    Circle(r) => 3.14 * r * r,
    Rect(w, h) => w * h
  }
```

- `match x { pat => e, pat => e }`: braces, commas, `=>`, exhaustive. `if c then a else b` (never `if c { }`).
- `let v = expr?` unwraps `Ok`/`Some`, or returns early with `Err`/`None` (let-bound only).
- Lambdas: `\x. x * 2`; multi-arg `\acc x. acc + x`, called `f(a, b)`. Local recursion: `letrec f = \n. ...`.
- Pipe: `xs |> filter(\x. x > 0, _) |> map(\x. x * 2, _)`. One `_` marks where the left side goes; `x |> f` calls unary `f`.

## Check, verify, test

```bash
ailang check file.ail            # type and effect check; `_?` is a typed hole
ailang check --fix file.ail      # auto-apply safe fixes (`;`, missing effects, string concatenation)
ailang check --verify file.ail   # Z3-prove requires/ensures
ailang test file.ail             # inline `tests [((a, b), expected)]` and contracts
```

## Find the stdlib before hand-rolling

```bash
ailang docs --list               # all stdlib modules
ailang docs std/list             # exports with signatures
```

- Use camelCase names. `range(0, n)` takes two args, end exclusive. `sortBy(cmp, xs)`.
- Result and int helpers: `mapResult(f, xs)`, `collect(rs)` in `std/result`; `minInt`, `maxInt`, `clampInt(x, lo, hi)` in `std/math`.
- Multi-module: `import myapp/data (User)`, or `import ./data (User)` inside a package.

## Not AILANG

`for`/`while`, `var`, `x = x + 1`, a power operator (use `pow(2.0, 10.0)`), `list.map(f)` (use `map(f, list)`), `f(a)(b)` on multi-arg funcs (use `f(a, b)`), refutable `let Some(x) = o` (use `match`).
