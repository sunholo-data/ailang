What do these numbers mean?

ELO estimates model capability from task difficulty. Pass rate is the share of saved runs that passed. Cost per solved task includes the cost of failed attempts. Measured versions differ because saved evidence is reused. Different task sets are not a controlled AILANG-versus-Python comparison.
