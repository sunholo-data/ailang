# M-GAME-B: Effects for Games

**Status**: Planned
**Target Version**: v0.5.1
**Depends On**: M-GAME-A (Go Codegen Foundation)
**Estimated LOC**: 800

## Overview

Phase 2 of game engine support. Adds deterministic effects essential for game development:
- **Rand**: Seeded random number generation for reproducible gameplay
- **Clock**: Frame timing for game loops
- **Extern handlers**: Stubs for Go code to provide effect implementations

## Motivation

Games require:
1. **Deterministic randomness** - Same seed → same gameplay (replays, testing, netcode)
2. **Frame timing** - Delta time for physics, animations
3. **Extern integration** - Go code provides actual implementations (SDL, Raylib, etc.)

## Design Decisions (LOCKED)

### D1: Rand Effect with Explicit Seeds

```ailang
-- Rand effect requires a seed for determinism
effect Rand {
  random_int: int -> int -> int   -- random_int(min, max)
  random_float: float -> float -> float
  random_bool: () -> bool
}

-- Usage: seed passed at effect boundary
export func roll_dice() -> int ! Rand {
  random_int(1, 6)
}
```

**Rationale**: Explicit seeds enable:
- Deterministic replays
- Network synchronization
- Automated testing

### D2: Clock Effect for Frame Timing

```ailang
effect Clock {
  delta_time: () -> float   -- Seconds since last frame
  total_time: () -> float   -- Total elapsed time
  frame_count: () -> int    -- Current frame number
}

export func update_position(pos: float, vel: float) -> float ! Clock {
  let dt = delta_time() in
  pos + vel * dt
}
```

**Rationale**: Frame timing is fundamental to game loops. Abstracting as an effect allows:
- Testing with fixed timesteps
- Slow-motion/fast-forward
- Deterministic physics

### D3: Extern Handler Pattern

Generated Go code uses handler interfaces that game code implements:

```go
// Generated by ailang
type RandHandler interface {
    RandomInt(min, max int64) int64
    RandomFloat(min, max float64) float64
    RandomBool() bool
}

type ClockHandler interface {
    DeltaTime() float64
    TotalTime() float64
    FrameCount() int64
}

// Game code provides implementations
type MyRandHandler struct {
    rng *rand.Rand
}

func (h *MyRandHandler) RandomInt(min, max int64) int64 {
    return min + h.rng.Int63n(max-min+1)
}
```

**Rationale**: Handler pattern allows:
- Go code to provide platform-specific implementations
- Easy mocking for tests
- No runtime reflection needed

### D4: Effect Registration at Module Level

```go
// Generated module initialization
func Init(rand RandHandler, clock ClockHandler) *Module {
    return &Module{
        rand:  rand,
        clock: clock,
    }
}

// Calling AILANG functions
func (m *Module) RollDice() int64 {
    return m.rollDice(m.rand)
}
```

## Testing Strategy

1. **Unit tests**: Each builtin tested in isolation
2. **Integration tests**: Full pipeline from AILANG to Go
3. **Determinism tests**: Same seed → same output across runs

## Non-Goals for This Phase

- Async/concurrent effects (Phase 4)
- Network effects (future)
- File I/O effects (already exist in std/fs)
- Graphics/audio effects (game code provides via handlers)

## Example: Complete Game Loop

```ailang
module game

import std/rand
import std/clock

type GameState = {
  player_x: float,
  player_y: float,
  score: int
}

export func init_state(seed: int) -> GameState ! Rand {
  { player_x: random_float(0.0, 100.0),
    player_y: random_float(0.0, 100.0),
    score: 0 }
}

export func update(state: GameState, input: Input) -> GameState ! Clock {
  let dt = delta_time() in
  { state with
    player_x: state.player_x + input.dx * dt,
    player_y: state.player_y + input.dy * dt }
}
```
