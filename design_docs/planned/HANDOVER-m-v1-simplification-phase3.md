## Traps measured in this program (each cost real time)

- **The interactive shell shadows `grep` with ugrep.** Scripts run under `/bin/bash` get BSD grep: no BRE `\|`, and `grep -q` on a pipe under `pipefail` reads as FALSE (SIGPIPE). Test every script with `/bin/bash script.sh`; use `grep -E '(a|b)'` and `grep pattern >/dev/null`. The metrics script hid a 4-package leak this way for a day.
- **Another agent's `git commit` in the shared checkout sweeps YOUR staged files into its commit.** Happened twice. Stage and commit in ONE command; never leave an index staged.
- **`tools/launchd/install_*.sh` re-renders plists from the template**; a key someone added to the installed plist by hand is LOST (the rig coordinator silently came up on the local plane once). Diff the installer's `.bak` against the new plist every time; the template is the source of truth (`AILANG_STORAGE=gcp` now lives there).
- **Test failure messages that print header values print credentials.** A `%q` of an `Authorization` header put the rig's coordinator key into a session transcript; the key was rotated. Assert on lengths/presence, and home-isolate anything that discovers keys from `$HOME` (`testutil.SetHomeDir`, never `t.Setenv("HOME")` — `make check-home-isolation` gates it).
- **A retired env var in a long-lived shell breaks language commands** if the plane is resolved eagerly. The fix pattern: defer the error into the component that needs it (`internal/runner/secret_approver.go`'s `deferredPlaneError`). Ops commands hard-error on retired names; `ailang run` never cares.
- **Auto-mode refuses LaunchAgent plist edits and `launchctl` persistence** from the agent; the installer scripts are the sanctioned route, and Mark runs them when asked.
- **`.golangci.yml` v1 `issues.exclude-*` keys were silently ignored under v2** for months. Prove a lint rule with a canary (plant a violation, see it flagged, remove it).
- **A single gate that keeps missing by a definitional amount is a wrong metric, not a failing codebase** — but move it ONCE with the reason written down (closure 36 → 40 → 42, then split leaf/non-leaf). Do not move a gate a third time.
