### M1: TOML Schema (~70 LOC, Day 1 morning)

Add `ExtensionRegistryConfig` to `PackageManifest` following the `AIProviders []AIProviderSpec` pattern.

**Tasks:**
- [ ] Add `ExtensionRegistryConfig` struct to `internal/pkg/manifest.go`:
  ```go
  type ExtensionRegistryConfig struct {
      Packages     []string `toml:"packages"`      // e.g. ["motoko-ext-compaction@0.2.0"]
      ConfigImport string   `toml:"config_import"` // e.g. "src/core/config.RuntimeConfig"
      HooksImport  string   `toml:"hooks_import"`  // e.g. "src/core/ext/types.ExtensionHooks"
      Output       string   `toml:"output"`        // default: "registry_generated.ail"
      ModuleName   string   `toml:"module_name"`   // default: derived from Output path
  }
  ```
- [ ] Add `Extensions ExtensionRegistryConfig \`toml:"extensions"\`` field to `PackageManifest` (after `AIProviders` line 27)

- [ ] Add `Validate()` check: same for `HooksImport`
- [ ] Write 5 unit tests in `internal/pkg/manifest_test.go`:

  - `Validate()` error: packages present but `config_import` missing
  - `Validate()` error: packages present but `hooks_import` missing
  - `Validate()` pass: packages + both imports present

### M2: Generator Command (~130 LOC, Day 1 afternoon)

New `cmd/ailang/ext_registry_gen.go` implementing the full generator.

**Tasks:**
- [ ] Create `cmd/ailang/ext_registry_gen.go`:
  - `extRegistryGenCommand(args []string) error` — entry point
  - `--config FILE` flag (default: `ailang.toml`)
  - `--output FILE` flag (overrides `ailang.toml` `output` value)
  - `--dry-run` flag — print to stdout, don't write
  - `deriveShortName(pkgName string) string`:
    - Strip `@version` suffix first: `motoko-ext-exa-search@0.4.1` → `motoko-ext-exa-search`
    - Strip `motoko-ext-` prefix if present: → `exa-search`
    - Replace `-` with `_`: → `exa_search`
  - `stripVersion(pkgRef string) string` — splits on `@`, returns name part
  - `verifyPackageLocked(lf *pkg.LockFile, pkgName string) error` — `lf.FindPackage(pkgName)`, error if not found
  - `renderRegistry(cfg ExtensionRegistryConfig, pkgNames []string, moduleName string) string` — uses `text/template`
  - Template emits: module declaration, imports, `resolve()` function
  - Atomic write: write to `output + ".tmp"`, then `os.Rename`
  - Clear error if `ailang.toml` has no `[extensions]` section or empty `packages`
- [ ] Wire into `cmd/ailang/main.go`: `case "generate-extension-registry": if err := extRegistryGenCommand(flag.Args()[1:]); err != nil { ... }`
- [ ] Add to `ailang help` output

**Generated file shape (template):**
```
-- GENERATED by ailang generate-extension-registry
-- Source: ailang.toml [extensions]
-- Do not edit. Regenerate: ailang generate-extension-registry

module {{.ModuleName}}

{{range .Imports}}import {{.Path}}/register (register_with_config) as register_{{.Alias}}
{{end}}import {{.ConfigModule}} ({{.ConfigType}})
import {{.HooksModule}} ({{.HooksType}})
import std/option (Option, Some, None)

export func resolve(name: string, cfg: {{.ConfigType}}) -> Option[{{.HooksType}}] {
{{range $i, $pkg := .Packages}}  {{if $i}}else {{end}}if name == "{{$pkg.ShortName}}" then Some(register_{{$pkg.Alias}}(cfg))
{{end}}  else None
}
```

**Files:** `cmd/ailang/ext_registry_gen.go` (~130 LOC), `cmd/ailang/main.go` (+5 LOC)

**Acceptance criteria:**
- `ailang generate-extension-registry --help` prints usage
- `ailang generate-extension-registry --dry-run` on a fixture prints valid AILANG source
- `make test` green
