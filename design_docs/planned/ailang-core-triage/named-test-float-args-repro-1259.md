The new report adds an std/math-import repro and the "intermittent by shape" observation, which are useful colour for the eventual design doc but change neither the class nor the remedy space. #1259's recommendation stands: design-doc (elaboration/defaulting semantics for the synthesized test module, with the v0.22.0 `m-wasm-typecheck-float-divergence` and v0.11.4 `m-poly-ord-defaulting-regression` float-defaulting prior art).
