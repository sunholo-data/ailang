# AILANG v0.4 Roadmap Summary

**Status:** Updated 2025-10-19
**Based on:** Roadmap review and alignment with "AI-first language" vision

---

## Key Changes From Original Proposal

### 1. **Evidence-First Approach**
- **Before:** "AILANG is AI-native" (aspirational claim)
- **After:** "AILANG increased AI compile success by 49%" (empirical proof)
- **Impact:** Added M-EVAL benchmark data throughout VISION.md

### 2. **Split v0.4 Into Three Releases**
- **Before:** One v0.4.0 release with reflection (7 weeks)
- **After:** Three incremental releases (11 weeks total)
  - v0.4.0 (Week 7): Deterministic tooling ONLY (`normalize`, `suggest`, `apply`)
  - v0.4.1 (Week 9): Runtime reflection (monomorphic types)
  - v0.4.2 (Week 11): Training data export + polymorphic reflection (research-dependent)

**Rationale:** Reflection on polymorphic types is novel research. Don't block public launch on it.

### 3. **Concrete Use Cases Added**
- **Before:** "Programs that explain themselves" (vague)
- **After:** Three specific reflection use cases with code examples:
  1. Self-debugging (AIs fix missing `!: IO` declarations)
  2. Automated refactoring (AIs change `List[int]` → `List[string]`)
  3. Proof generation (AIs output machine-checkable execution traces)

### 4. **Multi-Agent Collaboration Detailed**
- **Before:** "Shared effect algebra" (buzzword)
- **After:** Concrete 2-agent example (Agent A refactors, Agent B verifies)
- **Shows:** How `reflectEffect` and `normalize` enable coordination

### 5. **"Why Not Python?" Section**
- **New addition:** Three concrete failure modes:
  1. Implicit state breaks AI reasoning (global variables)
  2. Multiple correct answers create non-deterministic generation (5 ways to map)
  3. Runtime type errors are silent failures (no exhaustive matching)
- **Each includes:** Python example, AI failure mode, AILANG solution

### 6. **Training Data Export Prioritized**
- **Before:** Not mentioned in roadmap
- **After:** v0.4.2 deliverable with concrete use case
- **Format:** `--emit-trace jsonl` outputs type inference steps, effect propagation, normalization
- **Application:** Self-supervised learning for AI models

### Must-Have (Blockers)
1. ✅ `ailang normalize file.ail` — canonical formatting
2. ✅ `ailang suggest-imports file.ail` — infer missing imports
3. ✅ `ailang apply edits.json file.ail` — deterministic code edits
4. ✅ Recursion combinators: `fold`, `unfold`, `iterateN`
5. ✅ Import ergonomics (prelude or glob imports)
6. ✅ Effect syntax sugar: `!: IO,FS`

### Success Criteria
- Compile success ≥75% on M-EVAL (up from 67%)
- Normalizer demonstrates +20pp lift on failing benchmarks
- Zero breaking changes to existing examples
- `ailang normalize` handles all 66 example files

## Critical Insights

### 1. **Evidence Over Aspiration**
Every claim in VISION.md now backed by M-EVAL data. "AI-native" isn't marketing—it's measurable improvement.

### 2. **Incremental > Big Bang**
v0.4.0 doesn't need reflection to prove deterministic tooling works. Ship tooling first, research later.

### 3. **Concrete > Abstract**
"Programs that explain themselves" → 3 specific use cases with code examples. Multi-agent "coordination" → 2-agent verification example.

### 4. **Reflection Is Hard**
Polymorphic types at runtime require research (type erasure vs reification). Don't block v0.4.0 on it.

### 5. **Training Data Is Undervalued**
`--emit-trace` enables self-supervised learning from AILANG execution. This is a **killer feature** for AI models.
