# AILANG Dev Tools Compact Reference v0.8.0

> Compact toolchain reference for AI agents. For syntax: `ailang prompt` | Full reference: `ailang devtools-prompt`

## 1. Running & Testing

```bash
ailang run --caps IO,FS --entry main module.ail     # Run module (flags BEFORE filename)
ailang run --caps IO,AI --ai gemini-2-5-flash m.ail  # Run with AI effect
ailang check module.ail                              # Type-check only
ailang check --timeout 30s module.ail                # Timeout + stack dump on hang
ailang check --json module.ail                       # JSON error output
ailang check src/                                    # Recursive directory check
ailang test --format json tests/                     # Run tests (JSON output)
ailang repl                                          # Interactive REPL
ailang iface <module>                                # Module interface (normalized JSON)
```

**Capabilities** (`--caps`): `IO` (print/readLine), `FS` (readFile/writeFile), `Net` (httpGet/httpRequest), `AI` (call/callJson), `Env` (getEnv), `Clock` (now). `Debug` is a ghost effect (always available, no `--caps` needed).

**Other `run` flags**: `--ai-stub`, `--seed <n>`, `--virtual-time`, `--compact`, `--quiet`, `--no-print`, `--args-json`, `--budget-report`, `--debug-types`, `--relax-modules`, `--allow-env`, `--env`, `--max-recursion-depth`, `--release`, `--log-level`

## 2. Traces & Debugging

```bash
ailang run --emit-trace jsonl --caps IO --entry main m.ail > trace.jsonl  # JSONL trace
ailang run --emit-trace otel --caps IO --entry main m.ail                 # Cloud Trace/OTEL
ailang run --debug-types --node 42 m.ail                                  # Type inference debug
ailang run --verify-contracts --caps IO --entry main m.ail                # Contract checks
```

**Trace events**: `module_start`, `function_enter`, `function_exit`, `effect`, `contract_check`, `budget_delta`, `error`

**Debug env vars**: `DEBUG_STRICT=1`, `DEBUG_PARSER=1`, `DEBUG_MONO_VERBOSE=1`, `DEBUG_CODEGEN=1`, `AILANG_RELAX_MODULES=1`

**In-program debugging** (Debug ghost effect — invisible, zero-cost in release):
```bash
ailang run --caps IO --entry main file.ail              # Debug output to stderr
ailang run --caps IO --log-level warn --entry main f.ail # Filter by severity
ailang run --release --caps IO --entry main f.ail        # Erase all Debug calls
```
Use `import std/debug (log, check)` or `import pkg/sunholo/logging/logger (info, warn)` instead of println/IO. No `! {Debug}` needed — ghost effect is invisible to callers.

## 2a. Static Contract Verification (Z3)

```bash
ailang verify file.ail              # Prove contracts (requires Z3)
ailang verify --json file.ail       # Machine-readable output
ailang verify --verbose file.ail    # Show generated SMT-LIB
ailang verify --strict file.ail     # Exit 1 on any failure
```

**Statuses**: `VERIFIED` (proved), `VIOLATION` (counterexample found), `SKIPPED` (outside decidable fragment), `ERROR`

**Decidable fragment**: int/bool/enum, arithmetic/comparison/logic, if/let/match, must be pure + non-recursive.

## 3. Replay & Determinism

```bash
ailang replay baseline.jsonl             # Compare against baseline (exit 0=match, 1=mismatch)
ailang replay --json baseline.jsonl      # JSON output
ailang replay --file modified.ail b.jsonl # Override source file
```

## 4. Training Data Export

```bash
ailang export-training --score trace.jsonl              # Score quality (human-readable)
ailang export-training --score --json traces/            # Score as JSON
ailang export-training --min-score 0.7 traces/           # Export filtered by quality
ailang export-training --output t.jsonl --source-dir src/ traces/
```

**Score components** (weighted 0.0-1.0): Completion (30%), Complexity (25%), Contracts (20%), Budget efficiency (15%), Effect diversity (10%)

## 5. Chains (Agent Execution Monitoring)

```bash
ailang chains list                          # All chains (most recent first)
ailang chains list --since 24h --agent X    # Filter by time/agent
ailang chains active                        # Running chains
ailang chains view <id> --spans             # Details with session/tool info
ailang chains tree <id> --detailed          # ASCII hierarchy with tools
ailang chains diff <id>                     # Git diff across stages
ailang chains find --github owner/repo#123  # Find by reference
ailang chains stats --by-agent              # Cost/token breakdown
ailang chains diagnose <id>                 # Health check
```

Short IDs work: `ailang chains view e9c7501d`

## 6. Coordinator (Task Delegation)

```bash
ailang coordinator start / stop / status    # Daemon management
ailang coordinator pending                  # Interactive approval (a=approve, r=reject, d=diff, c=chat)
ailang coordinator diff <task-id>           # View changes
ailang coordinator logs <task-id>           # Execution logs
ailang coordinator approve <task-id>        # Approve work
ailang coordinator reject <task-id> --feedback "reason"

# Send tasks to agents
ailang messages send coordinator "Fix bug" --title "Bug" --from "user" --type bug
ailang messages send design-doc-creator "Design X" --title "Feature" --from "user"
```

**Pipeline**: `GitHub Issue -> design-doc-creator -> [Approval] -> sprint-planner -> [Approval] -> sprint-executor -> [Approval] -> Merged`

## 7. Messaging

```bash
ailang messages list --unread               # Unread messages
ailang messages read <id>                   # Read content
ailang messages send <inbox> "msg" --title "T" --from "agent"
ailang messages send user "Bug" --type bug  # Auto-creates GitHub issue
ailang messages ack <id> / --all            # Mark read
ailang messages unack <id>                  # Mark unread (retry)
ailang messages forward --to <inbox> <id>   # Forward
ailang messages search "query" --neural     # Semantic search
ailang messages import-github --labels bug  # Import GitHub issues
ailang messages cleanup --older-than 7d     # Remove old messages
```

## 8. AI Eval Suite

```bash
ailang eval-suite --models gpt5-mini,claude-haiku-4-5  # Run benchmarks (one command!)
ailang eval-suite --full --skip-existing                # Extended suite, resume safe
ailang eval-compare baselines/v0.7.2 baselines/v0.7.3  # Compare results
ailang eval-report baselines/v0.7.3 v0.7.3 --format=json  # Update dashboard (preserves history)
ailang eval-analyze baselines/v0.7.3                    # Failure analysis
```

**Warning**: `eval-suite` OVERWRITES output dir. Run all models in ONE command.

## 11. Web & API

```bash
ailang serve-api --watch --cors --caps IO,AI ./api/  # Dev server with hot-reload
ailang serve-api --frontend ./ui --caps IO ./api/     # Serve React frontend too
ailang serve-api --mcp ./api/                         # MCP stdio (Claude Desktop/Cursor)
ailang serve-api --mcp-http ./api/                    # HTTP + MCP at /mcp/
ailang serve-api --routes-only ./api/                  # Only @route endpoints
ailang init web-app my-app                            # Scaffold new web app
# Auto-serves: /api/_meta/docs (Swagger UI), /api/_meta/redoc (ReDoc)
# Protocols:   /.well-known/agent.json (A2A), /a2a/ (JSON-RPC), /mcp/ (MCP)
# Annotations: @route("METHOD","/path"), @raw, @nowrap, @noexpose, @nomcp (MCP-only hide), @mcp_name("name")
# Request headers: _headers: Json param on @route (no @raw needed)
# MCP: -- doc comments = tool descriptions, named inputSchema, --routes-only filters
# MCP names: ^[a-zA-Z0-9_-]{1,64}$ (Claude Desktop strict); use @mcp_name to override
```

Key flags: `--port`, `--cors`, `--frontend <path>`, `--watch`, `--caps`, `--ai <model>`, `--mcp`, `--mcp-http`, `--routes-only`
