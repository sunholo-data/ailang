# AILANG v0.7.4 Compact - AI Teaching Prompt

AILANG is a **pure functional language** with Hindley-Milner type inference and algebraic effects. Use **recursion** (no loops), **pattern matching**, and **explicit effect declarations**.

**AILANG is NOT Python!** No `def`, `for`, `while`, `class`, or `if x:`.

## Required Program Structure

```ailang
module benchmark/solution

export func main() -> () ! {IO} {
  println(show(42))  -- println is in prelude, no import needed!
}
```

**Rules:**
1. First line MUST be `module path/name` matching file path
2. Use `println(show(value))` for numbers, `println(str)` for strings
3. **Inside `{ }` blocks: use `let x = e;` (semicolons). NEVER use `let x = e in`!**
4. No loops - use recursion

## println vs print

| Function | Import Required? | Behavior |
|----------|-----------------|----------|
| `println` | NO (prelude) | WITH newline |
| `print` | YES (`import std/io (print)`) | NO newline |

**Use `println` for most output.** Use `print` ONLY when building output on one line.

## Quick Reference Examples

**Print calculation:**
```ailang
module benchmark/solution
export func main() -> () ! {IO} = println(show(5 % 3))
```

**If-then-else (NO braces!):**
```ailang
module benchmark/solution
export func main() -> () ! {IO} {
  let x = 10;
  let msg = if x > 0 then "positive" else "not positive";
  println(msg)
}
```

**HTTP GET:**
```ailang
module benchmark/solution
import std/net (httpGet)
export func main() -> () ! {IO, Net} = println(httpGet("https://example.com"))
```

**Filter list recursively:**
```ailang
module benchmark/solution
export func filter(people: [{name: string, age: int}], minAge: int) -> [{name: string, age: int}] =
  match people {
    [] => [],
    p :: rest => if p.age >= minAge then p :: filter(rest, minAge) else filter(rest, minAge)
  }
```

**Record update (immutable):**
```ailang
module benchmark/solution
export func main() -> () ! {IO} {
  let person = {name: "Alice", age: 30, city: "NYC"};
  let older = {person | age: person.age + 1};
  println(person.name ++ ", " ++ show(person.age) ++ ", " ++ person.city);
  println(older.name ++ ", " ++ show(older.age) ++ ", " ++ older.city)
}
```

## What AILANG Does NOT Have

| Invalid | Use Instead |
|-----------|----------------|
| `for`/`while` loops | Recursion |
| `[x*2 for x in xs]` | `map(\x. x*2, xs)` or recursion |
| `var`/`let mut` | Immutable `let` bindings |
| `list.map()` | `map(f, list)` |
| `import "std/io"` | `import std/io (println)` |
| `{"key": "val"}` | `jo([kv("key", js("val"))])` |
| `f(a)(b)` for multi-arg func | `f(a, b)` - multi-arg funcs use commas |
| `if x { ... }` | `if x then ... else ...` - NO braces! |
| mixing `let x = e in` with `;` | Use ONE style consistently |
| `let (x, y) = tuple` | Use `match tuple { (x, y) => ... }` |
| `\(a, b). body` pair syntax | Use `func(a: T, b: U) -> R { body }` |
| nested `func f(...) =` | Use `let f = \x. body` for nested functions |
| `concat(a, b)` | `a ++ b` for string/list concatenation |

## Let Bindings: Block Style vs Expression Style

**Rule: Inside `{ }` blocks, use SEMICOLONS. With `=` bodies, use `in`.**

```ailang
-- Block style: curly braces + semicolons
export func main() -> () ! {IO} {
  let x = 1;
  let y = 2;
  println(show(x + y))
}

-- Expression style: equals + in
export func main() -> () ! {IO} =
  let x = 1 in
  let y = 2 in
  println(show(x + y))

-- WRONG: Using `in` inside `{ }` block causes scope errors
-- let x = 1 in   -- DON'T! Use semicolons in blocks
```

**Simple rule: See `{` -> use `;`. See `=` -> use `in`.**

## Function Calls: Multi-arg vs Curried (CRITICAL)

```ailang
-- MULTI-ARG FUNC: Call with commas f(a, b)
func add(a: int, b: int) -> int = a + b
let result = add(3, 4)      -- CORRECT: 7
-- let bad = add(3)(4)      -- WRONG: arity mismatch!

-- CURRIED LAMBDA: Call with chained f(a)(b)
let addC = \a. \b. a + b
let result = addC(3)(4)     -- CORRECT: 7
let add10 = addC(10)        -- Partial application!
-- let bad = addC(3, 4)     -- WRONG: arity mismatch!
```

| Definition | Call Style | Partial App? |
|------------|------------|--------------|
| `func f(a, b) = ...` | `f(a, b)` | No |
| `let f = \a. \b. ...` | `f(a)(b)` | Yes |

**foldl syntax (IMPORTANT):**
```ailang
-- RECOMMENDED: space-separated multi-param lambda
foldl(\acc x. acc + x, 0, xs)

-- VERBOSE: inline func with explicit types (also works)
foldl(func(acc: int, x: int) -> int { acc + x }, 0, xs)

-- WRONG: curried lambda (arity mismatch!)
-- foldl(\acc. \x. acc + x, 0, xs)
```

## Recursive Lambdas (letrec)

```ailang
-- WRONG: `let` for self-referential lambda
-- let factorial = \n. if n <= 1 then 1 else n * factorial(n - 1);  -- ERROR

-- RIGHT: use `letrec` for recursive lambdas
letrec factorial = \n. if n <= 1 then 1 else n * factorial(n - 1);
println(show(factorial(5)))  -- 120
```

| Case | Use |
|------|-----|
| Top-level recursive function | `func f(...) = ...` (preferred) |
| Recursive lambda inside block | `letrec f = \x. ... f(...)` |
| Non-recursive lambda | `let f = \x. ...` |

## Effects (Side Effects Must Be Declared)

```ailang
pure func add(x: int, y: int) -> int = x + y          -- No effects
func greet(name: string) -> () ! {IO} = println("Hi " ++ name)  -- IO
func process(path: string) -> () ! {IO, FS} {          -- Multiple
  let content = readFile(path);
  println(content)
}
```

**Common effect combinations:**
| Task | Required Effects |
|------|------------------|
| Print output | `! {IO}` |
| Read files | `! {FS}` (add IO if also printing) |
| HTTP requests | `! {Net}` (add IO if also printing) |
| Environment vars | `! {Env}` |
| AI calls | `! {AI}` |

|--------|-----------|--------|

## String Parsing (Returns Option)

`stringToInt` returns `Option[int]` - you MUST pattern match:
```ailang
match stringToInt("42") {
  Some(n) => println("Parsed: " ++ show(n)),
  None => println("Invalid number")
}
```

## Constructing Option and Result

```ailang
import std/option (Option, Some, None)
pure func safeDivide(a: int, b: int) -> Option[int] =
  if b == 0 then None else Some(a / b)

-- Result: Ok(a) uses type param, Err(string) always string
type Result[a] = Ok(a) | Err(string)
pure func parseAge(s: string) -> Result[int] =
  match stringToInt(s) {
    Some(n) => if n >= 0 then Ok(n) else Err("negative"),
    None => Err("not a number")
  }
```

## Pattern Matching

**CRITICAL: Multiple let bindings in match arm need `{ }`:**
```ailang
-- WRONG: multiple lets without braces
match queue {
  [] => result,
  node :: rest =>
    let x = process(node);
    let y = update(x);        -- ERROR
    recurse(rest, y)
}

-- CORRECT: wrap in { }
match queue {
  [] => result,
  node :: rest => {
    let x = process(node);
    let y = update(x);
    recurse(rest, y)
  }
}
```

**On lists:** `match xs { [] => 0, x :: rest => x + sum(rest) }`

**On ADTs:** `match tree { Leaf(n) => n, Node(l, v, r) => size(l) + 1 + size(r) }`

**On Option:** `match result { Some(x) => x, None => defaultValue }`

**On Records:**
- `{name}` - shorthand binding
- `{name: n}` - renaming
- `{name, age}` - multiple fields
- `{user: {name}}` - nested records
- `{name, ...}` - rest pattern (ignores extra fields)

## JSON

**Build JSON:**
```ailang
import std/json (encode, jo, ja, kv, js, jnum, jb, jn)
-- js(string), jnum(float), jb(bool), jn() for null
-- jo([kv(k,v)...]) for objects, ja([...]) for arrays

let json = encode(jo([kv("name", js("Alice")), kv("age", jnum(30.0))]))
```

**Decode JSON (returns Result):**
```ailang
import std/json (decode, getString, getInt, asArray)
import std/option (Some, None)
import std/result (Ok, Err)

match decode("{\"name\":\"Alice\",\"age\":30}") {
  Ok(obj) => {
    match getString(obj, "name") { Some(n) => println(n), None => () };
    match getInt(obj, "age") { Some(a) => println(show(a)), None => () }
  },
  Err(e) => println("Error: " ++ e)
}
```

**JSON accessors:** `getString`, `getNumber`, `getInt`, `getBool`, `getArray`, `getObject` (by key) and `asString`, `asNumber`, `asBool`, `asArray` (direct conversion). Use `asArray` for top-level JSON arrays.

## Contracts (requires/ensures)

```ailang
export func safeDivide(dividend: int, divisor: int) -> int ! {}
requires { divisor != 0 }
ensures { result >= 0 }
{
  if dividend < 0 then (0 - dividend) / divisor
  else dividend / divisor
}
```

**Rules:**
- `requires { expr }` - precondition at entry
- `ensures { expr }` - postcondition, `result` refers to return value
- Contracts go BETWEEN effect annotation and function body
- `ailang verify file.ail` - static Z3 verification
- `--verify-contracts` flag - runtime checking

## Module Import Rules

**Imports are NOT transitive.** Each module must import what it directly uses.

```ailang
-- Module B uses readFile internally
module myapp/db
import std/fs (readFile)
export func loadConfig() -> string ! {FS} = readFile("config.json")

-- Module A must import std/fs itself to use readFile
module myapp/main
import std/fs (readFile)        -- REQUIRED: not inherited from myapp/db
import myapp/db (loadConfig)
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| `print(42)` | `print(show(42))` - print needs string |
| `import "std/io"` | `import std/io (println)` - no quotes |
| `list.map(f)` | `map(f, list)` - standalone function |
| `for x in xs` | Use recursion or `map`/`filter` |
| Missing `! {IO}` | Add effect to function signature |
| `let x = 1; let y = 2` at top level | Wrap in `{ }` block |
| Multiple lets in match arm without `{ }` | Wrap in `{ }` block |
| `module benchmark/myname` | Use exactly `module benchmark/solution` |
| Using reserved keyword as name | Use alternative name (43 reserved keywords) |
| Expecting transitive imports | Each module imports its own dependencies |
