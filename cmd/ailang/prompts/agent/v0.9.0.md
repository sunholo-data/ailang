# AILANG Agent Coding Guide

> Minimal reference for iterative agentic coding. For full syntax: `ailang prompt` | For toolchain: `ailang devtools-prompt`

## Workflow: Write → Check → Run → Fix

```bash
ailang check file.ail                                    # Type-check (fast, no execution)
ailang run --caps IO --entry main file.ail               # Run with IO capability
ailang run --caps IO,FS,Process --entry main file.ail    # Multiple capabilities
ailang prompt                                            # Full syntax reference (if stuck)
ailang examples search "json"                            # Find working examples
ailang docs std/string                                   # View module docs
```

**Flags MUST come BEFORE the filename.**

## Module Structure (Every .ail file)

```ailang
module path/to/module

import std/result (Result, Ok, Err)
import std/list (map, filter)

export func main() -> () ! {IO} {
  println("hello")
}
```

- **`export` is REQUIRED** on entry-point functions — `export func main()`, not `func main()`
- Module path should match file location from project root
- `--entry main` tells the runtime which function to call
- For quick prototyping: `--relax-modules` skips module path validation

## Effects & Capabilities

Every side effect must be declared in the function signature and enabled via `--caps`:

```ailang
func greet(name: string) -> () ! {IO} {
  println("Hello " ++ name)
}

func readConfig(path: string) -> string ! {FS} {
  readFile(path)
}

func fetchData(url: string) -> string ! {Net} {
  httpGet(url)
}
```

### Prelude Functions (Always Available — NO Import Needed)

These functions are available in every module without any import:

| Function | Type | Description |
|----------|------|-------------|
| `println(x)` | `string -> () ! {IO}` | Print string with newline |
| `print(x)` | `string -> () ! {IO}` | Print string without newline |
| `show(x)` | `a -> string` | Convert ANY value to string (ints, floats, bools, ADTs, records, lists) |
| `readLine()` | `() -> string ! {IO}` | Read line from stdin |
| `getArgs()` | `() -> [string] ! {IO}` | Get command-line arguments |

**Do NOT import these** — `import std/io (println)` creates a module-scoped binding that shadows the prelude. Just use `println(...)` directly. There is no `std/builtin` module.

**Requires explicit import:** `exit(code)` — `import std/io (exit)` then `exit(1)` to terminate with a non-zero exit code.

### Capabilities

| Cap | `--caps` | Key functions | Module |
|-----|----------|---------------|--------|
| `IO` | `IO` | (prelude: `println`, `show`, `readLine`, `getArgs`) | prelude (no import) |
| `FS` | `FS` | `readFile`, `writeFile`, `fileExists`, `listDir`, `mkdir`, `mkdirAll`, `isDir`, `isFile`, `removeFile`, `readFileBytes`, `writeFileBytes`, `appendFile` | `std/fs` |
| `Net` | `Net` | `httpGet`, `httpPost`, `httpRequest` | `std/net` |
| `Clock` | `Clock` | `now`, `sleep` | `std/clock` |
| `AI` | `AI` | `call`, `callJson` | `std/ai` |
| `Env` | `Env` | `getEnv`, `getEnvOr`, `getArgs` | `std/env` |
| `Process` | `Process` | `exec` | `std/process` |
| `Stream` | `Stream` | `connect`, `transmit`, `onEvent`, `selectEvents`, `asyncExecProcess` | `std/stream` |
| `Debug` | `Debug` | `log`, `check` | `std/debug` |

**Missing `--caps`** = compile error. Add what the error tells you.

## Core Syntax Quick Reference

```ailang
-- Comments
let x = 42                                    -- Immutable binding
let name: string = "AILANG"                   -- With type annotation
let add = \x. \y. x + y                       -- Lambda
func double(n: int) -> int = n * 2            -- Equation-form function
func greet() -> () ! {IO} { println("hi") }  -- Block-form function with effect

-- Pattern matching
match result {
  Ok(value) => println(value),
  Err(msg) => println("error: " ++ msg)
}

-- ADTs
type Shape = Circle(float) | Rect(float, float)

-- Records
let point = { x: 1.0, y: 2.0 }
let moved = { point | x: point.x + 1.0 }     -- Record update

-- Lists
let xs = [1, 2, 3]
let ys = map(\x. x * 2, xs)

-- Blocks (sequencing with effects)
{
  println("step 1");
  println("step 2");
  let result = readFile("data.txt");
  result
}

-- String operations
"hello" ++ " " ++ "world"                     -- Concatenation
show(42)                                       -- "42" (any value → string)
println("area = " ++ show(3.14 * r * r))      -- Display computed values
```

## Debugging

```bash
# Debug is a ghost effect — no --caps Debug needed, output goes to stderr
ailang run --caps IO --entry main file.ail
# Filter by level: --log-level warn|error|none
# Erase in production: --release
```

```ailang
import std/debug (log, check)

-- No ! {Debug} needed — ghost effect is invisible to callers
func process(x: int) -> int {
  check(x >= 0, "x must be non-negative");
  log("processing " ++ show(x));
  x * 2
}
```

```bash
# Compiler/runtime debugging
ailang check --timeout 30s file.ail            # Detect hangs with stack dump
ailang check --debug-compile file.ail          # Phase timing breakdown
ailang run --emit-trace jsonl --caps IO --entry main file.ail  # Execution trace
DEBUG_PARSER=1 ailang run file.ail             # Token position tracing
```

## Process Execution (Running External Commands)

```ailang
import std/process (exec)
import std/result (Result, Ok, Err)
import std/bytes (toString)

export func main() -> () ! {IO, Process} {
  match exec("echo", ["hello", "world"]) {
    Ok(out) => println(toString(out.stdout)),
    Err(NotFound(cmd)) => println("not found: " ++ cmd),
    Err(Timeout(ms)) => println("timed out"),
    Err(_) => println("error")
  }
}
```

```bash
ailang run --caps IO,Process --entry main file.ail
ailang run --caps IO,Process --process-timeout 10s --entry main file.ail
ailang run --caps IO,Process --process-allowlist "echo,curl" --entry main file.ail
```

- `exec` returns `Result[ProcessOutput, ProcessError]`
- **Ok for ALL completed processes** (even non-zero exit) — check `out.exitCode`
- **Err only for infrastructure failures** (NotFound, Timeout, PermissionDenied, etc.)
- stdout/stderr are `bytes` — use `std/bytes.toString` to decode

## Subprocess Stdin Writing

```ailang
import std/process (spawnProcess, writeProcessStdin, closeProcessStdin)
import std/bytes (fromString)
import std/result (Ok, Err)

export func main() -> () ! {Process, IO} {
  let handle = spawnProcess("cat", []);
  match writeProcessStdin(handle, fromString("hello\n")) {
    Ok(_) => println("wrote"),
    Err(e) => println("error: " ++ e)
  };
  closeProcessStdin(handle)
}
```

- `spawnProcess` spawns subprocess with writable stdin; stdout/stderr discarded
- `writeProcessStdin` writes bytes (non-blocking, returns `Result[(), string]`)
- `closeProcessStdin` signals EOF — subprocess exits
- Requires `--caps Process` only (not Stream)

## Common Patterns

### JSON parsing and field access
```ailang
import std/json (decode, getString, getNumber, asArray, Json, JObject, JArray, JString, JNumber)
import std/result (Result, Ok, Err)
import std/option (Option, Some, None)
import std/list (map, filter)

export func main() -> () ! {IO} {
  -- Decode JSON
  let data = decode("{\"name\": \"test\", \"items\": [{\"id\": 1}, {\"id\": 2}]}");
  match data {
    Ok(obj) => {
      -- Access string field: getString(json, key) -> Option[string]
      match getString(obj, "name") {
        Some(n) => println("name: " ++ n),
        None => println("no name")
      };
      -- Access array field: asArray returns Option[[Json]]
      match asArray(obj) {
        Some(items) => println("items: " ++ show(items)),
        None => println("not an array")
      }
    },
    Err(e) => println("parse error: " ++ e)
  }
}
```

**JSON accessor cheat sheet:**
- `getString(json, key)` → `Option[string]` | `getNumber(json, key)` → `Option[float]`
- `getBool(json, key)` → `Option[bool]` | `getArray(json, key)` → `Option[[Json]]`
- `asArray(json)` → `Option[[Json]]` | `asString(json)` → `Option[string]`
- Pattern match on `Json` ADT: `JString(s)`, `JNumber(n)`, `JBool(b)`, `JArray(items)`, `JObject(pairs)`, `JNull`

### File I/O
```ailang
import std/fs (readFile, writeFile)

export func main() -> () ! {IO, FS} {
  let content = readFile("input.txt");
  writeFile("output.txt", "processed: " ++ content);
  println("done")
}
```

### HTTP requests
```ailang
import std/net (httpGet)

export func main() -> () ! {IO, Net} {
  let body = httpGet("https://httpbin.org/get");
  println(body)
}
```

## Standard Library Quick Reference

**Import what you use:** `import std/list (map, foldl, filter)`

### std/list — List operations
`map(f, xs)`, `filter(f, xs)`, `foldl(\acc. \x. ..., init, xs)`, `foldr(\x. \acc. ..., init, xs)`, `length(xs)`, `head(xs)`, `tail(xs)`, `nth(xs, i)`, `reverse(xs)`, `zip(xs, ys)`, `range(start, end)`, `concat(xss)`, `any(f, xs)`, `all(f, xs)`, `sort(xs)`, `sortBy(f, xs)`

### std/string — String operations
`split(sep, s)` → `[string]`, `join(sep, parts)`, `trim(s)`, `contains(s, sub)` → `bool`, `startsWith(s, pre)`, `endsWith(s, suf)`, `length(s)` → `int`, `replace(old, new, s)`, `substring(s, start, len)`, `toUpper(s)`, `toLower(s)`, `stringToInt(s)` → `Result[int, string]`, `stringToFloat(s)` → `Result[float, string]`, `charAt(s, i)` → `string`

### std/option — Optional values
`type Option[a] = Some(a) | None` — import: `import std/option (Option, Some, None)`
`map(f, opt)`, `withDefault(default, opt)`, `isSome(opt)`, `isNone(opt)`

### std/result — Error handling
`type Result[a, e] = Ok(a) | Err(e)` — import: `import std/result (Result, Ok, Err)`
`map(f, res)`, `mapErr(f, res)`, `withDefault(default, res)`, `isOk(res)`, `isErr(res)`

### std/math — Math functions
`sqrt(x)`, `abs(x)`, `floor(x)`, `ceil(x)`, `round(x)`, `pow(base, exp)`, `min(a, b)`, `max(a, b)`, `pi`, `log(x)`, `mod(a, b)`

### std/json — JSON parsing (see Common Patterns above for full example)
`decode(s)` → `Result[Json, string]`, `encode(json)` → `string`
Accessors: `getString(j, key)`, `getNumber(j, key)`, `getBool(j, key)`, `getArray(j, key)`, `getObject(j, key)` — all return `Option[T]`
Direct: `asArray(j)`, `asString(j)`, `asNumber(j)` — unwrap without key lookup
ADT: `JString(s)`, `JNumber(n)`, `JBool(b)`, `JArray(items)`, `JObject(pairs)`, `JNull`

### std/bytes — Byte operations
`toString(b)` → `string`, `fromString(s)` → `bytes`, `length(b)` → `int`

### Other modules
`std/fs`: `readFile(path)`, `writeFile(path, content)`, `appendFile(path, content)`, `readFileBytes(path)`, `writeFileBytes(path, b)`, `fileExists(path)`, `listDir(path)`, `mkdir(path)`, `mkdirAll(path)`, `isDir(path)`, `isFile(path)`, `removeFile(path)`
`std/net`: `httpGet(url)`, `httpPost(url, body)`, `httpRequest(method, url, headers, body)`
`std/clock`: `now()` → `int`, `sleep(ms)`
`std/env`: `getEnv(key)`, `getEnvOr(key, default)`
`std/process`: `exec(cmd, args)` → `Result[ProcessOutput, ProcessError]`

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| `ailang run file.ail --caps IO` | Flags BEFORE filename: `ailang run --caps IO file.ail` |
| Missing effect in signature | Add `! {IO}` (or whatever the error says) to return type |
| `if x > 0 { ... }` | Must have else: `if x > 0 then "yes" else "no"` |
| `func main() { ... }` | Need return type: `func main() -> () ! {IO} { ... }` |
| `func main() -> () ! {IO} { ... }` | Must be exported: `export func main() -> () ! {IO} { ... }` |
| `import std/io (println)` | `println` is prelude — no import needed. Just use it directly. |
| `import std/builtin` | No such module. `println`, `show` are prelude (always available). |
| `import std/result` | Import what you use: `import std/result (Result, Ok, Err)` |
| Mutable variables | Everything is immutable. Use recursion or fold for accumulation. |
| `x = x + 1` | No mutation. Use `let newX = x + 1` |
| `return value` | No return keyword. Last expression is the return value. |
| `foldl(f, init, xs)` | Lambda params need dots: `foldl(\acc. \x. acc + x, 0, xs)` |
| Accessing JSON fields | Use `getString(obj, "key")`, NOT `obj.key` or `obj["key"]` |
| Don't know function names | `ailang docs std/module` to see all exports and types |
