## Quick Reference

| Element | Syntax | Notes |
|---------|--------|-------|
| Module | `module path/to/name` | First line, required |
| Import | `import "std/io" (println)` | Selective imports |
| Function | `export func name(x: int) -> int { x }` | Use `func` not `fn` |
| Lambda | `\x. x * 2` or `func(x: int) -> int { x * 2 }` | Two syntaxes |
| Effect | `-> () ! {IO}` | After return type |
| Pattern | `match x { \| 0 => a \| n => b }` | Use `=>` not `:` or `->` |
| ADT | `type Tree = \| Leaf(int) \| Node(Tree, int, Tree)` | Leading `\|` optional |
| Record | `{name: "Alice", age: 30}` | No trailing commas |
| Update | `{base \| field: newValue}` | Functional |
| Block | `{ stmt1; stmt2; expr }` | Semicolons required |
| Comment | `-- comment` | Double dash |

**Commands:**
- `ailang run --caps IO,FS --entry main file.ail` - Flags BEFORE filename
- `ailang builtins list --by-module` - Complete builtin reference
- `ailang repl` - Interactive REPL with `:type expr`

**Details:** See [docs/guides/](../docs/guides/) | [examples/](../examples/) (66 files)

## Critical: What AILANG is NOT

❌ **NO imperative syntax:**
```python
# WRONG - Python/JavaScript style
for i in range(10):
    print(i)

total = 0
def add(x):
    global total
    total += x
```

✅ **YES functional style:**
```ailang
module benchmark/solution
import std/io (println)

-- Recursion instead of loops
export func loop(n: int) -> () ! {IO} {
  if n > 10 then () else { println(show(n)); loop(n + 1) }
}
```

**Common mistakes:**
- Using `loop`, `for`, `while`, `break` → Use recursion
- Assignment statements (`x = x + 1`) → Use `let` bindings
- Mutable state → Thread state explicitly
- Single-line without module → Every file needs `module path/name`

## Mandatory Structure

```ailang
module benchmark/solution              -- 1. Module (required, first line)
import std/io (println)                -- 2. Imports (if needed)
export func main() -> () ! {IO} {      -- 3. Functions
  println("Hello")
}
```

## Syntax Rules (Critical)

| Rule | Correct | Wrong |
|------|---------|-------|
| Function keyword | `func` | `fn`, `function`, `def` |
| ADT syntax | `type Tree = Leaf \| Node` | `type Tree { }`, `enum Tree` |
| Pattern arrow | `=> expr` | `: expr`, `-> expr` |
| Block separator | `stmt1; stmt2` | `stmt1 stmt2`, `stmt1, stmt2` |
| Namespace | Constructor names directly | `Module::Constructor` |
| Effects | `! {IO}` after return type | `effect IO`, `throws IO` |

## Type System (Hindley-Milner + Row Polymorphism)

**Primitives:** `int`, `float`, `string`, `bool`
**Compounds:** `List[a]`, `{field: type}`, `Maybe[a]`, `Result[a, e]`
**Details:** [docs/guides/types.md](../docs/guides/types.md)

**Type annotations (optional but recommended):**
```ailang
let add : (int, int) -> int = func(a: int, b: int) -> int { a + b }
```

**Row polymorphism (records with partial fields):**
```ailang
let getName : forall a. {name: string | a} -> string =
  func(r: {name: string | a}) -> string { r.name }
```

## Effect System

**Syntax:** `! {IO, FS, Net}` after return type
**Grant:** `ailang run --caps IO,FS file.ail`

| Effect | Capability | Builtins |
|--------|------------|----------|
| `IO` | Console I/O | `println`, `readLine`, `print` |
| `FS` | File system | `readFile`, `writeFile`, `listDir` |
| `Net` | HTTP requests | `httpRequest` |
| `Clock` | Time operations | `getCurrentTime` |

**Example:**
```ailang
export func fetchData(url: string) -> Result[string, string] ! {Net, IO} {
  match httpRequest(url, "GET", [], "") {
    | Ok(resp) => { println("Status: " ++ show(resp.status)); Ok(resp.body) }
    | Err(e) => Err("HTTP failed")
  }
}
```

**Details:** [docs/guides/effects.md](../docs/guides/effects.md)

## Pattern Matching

**Syntax:** `match expr { | pattern => body }`

```ailang
type Maybe[a] = Nothing | Just(a)

let unwrap : forall a. (Maybe[a], a) -> a = func(m: Maybe[a], default: a) -> a {
  match m {
    | Nothing => default
    | Just(x) => x
  }
}
```

**Must be exhaustive or use wildcard:**
```ailang
match x {
  | 0 => "zero"
  | 1 => "one"
  | _ => "other"  -- Wildcard required!
}
```

## Algebraic Data Types (ADTs)

```ailang
-- Single-line (compact)
type Tree[a] = Leaf(a) | Node(Tree[a], a, Tree[a])

-- Multi-line (readable)
type Result[a, e] =
  | Ok(a)
  | Err(e)

-- Recursive
type List[a] = Nil | Cons(a, List[a])
```

**Usage:**
```ailang
let tree = Node(Leaf(1), 2, Leaf(3))
match tree {
  | Leaf(x) => x
  | Node(l, x, r) => x
}
```

## Records

**Create:** `{field1: value1, field2: value2}`
**Access:** `record.field`
**Update:** `{record | field: newValue}` (functional, returns new record)

```ailang
let person = {name: "Alice", age: 30}
let older = {person | age: person.age + 1}  -- Alice is still 30!
```

## List Operations

| Operation | Syntax | Example |
|-----------|--------|---------|
| Empty | `[]` | `let empty : List[int] = []` |
| Cons | `::(head, tail)` | `::(1, ::(2, []))` |
| Match | `\| [] => ... \| ::(h, t) => ...` | See example below |
| Prepend | Use `::(x, xs)` | Build lists recursively |

**Canonical patterns:**
```ailang
-- Map
let map : forall a b. ((a) -> b, List[a]) -> List[b] =
  func(f: (a) -> b, xs: List[a]) -> List[b] {
    match xs {
      | [] => []
      | ::(h, t) => ::(f(h), map(f, t))
    }
  }

-- Filter
let filter : forall a. ((a) -> bool, List[a]) -> List[a] =
  func(pred: (a) -> bool, xs: List[a]) -> List[a] {
    match xs {
      | [] => []
      | ::(h, t) => if pred(h) then ::(h, filter(pred, t)) else filter(pred, t)
    }
  }

-- Fold
let foldl : forall a b. ((b, a) -> b, b, List[a]) -> b =
  func(f: (b, a) -> b, acc: b, xs: List[a]) -> b {
    match xs {
      | [] => acc
      | ::(h, t) => foldl(f, f(acc, h), t)
    }
  }
```

## Higher-Order Functions

**Functions are values:**
```ailang
let apply : forall a b. ((a) -> b, a) -> b = func(f: (a) -> b, x: a) -> b { f(x) }
let compose : forall a b c. ((b) -> c, (a) -> b) -> (a) -> c =
  func(g: (b) -> c, f: (a) -> b) -> (a) -> c {
    func(x: a) -> c { g(f(x)) }
  }
```

## Explicit State Threading

**NO global mutable state. Pass state explicitly:**
```ailang
-- State is (total, count)
let processLoop : (int, int, List[int]) -> (int, int) =
  func(total: int, count: int, xs: List[int]) -> (int, int) {
    match xs {
      | [] => (total, count)
      | ::(x, rest) => processLoop(total + x, count + 1, rest)
    }
  }
```

## Common Mistakes Checklist

- [ ] Module declaration first: `module path/name`
- [ ] Import before use: `import "std/io" (println)` before calling `println`
- [ ] Full stdlib paths: `"std/io"` not `"io"`
- [ ] Flags before filename: `ailang run --caps IO file.ail`
- [ ] Semicolons in blocks: `{ stmt1; stmt2; expr }`
- [ ] Effect annotations: `-> () ! {IO}` for side effects
- [ ] Pattern match exhaustive or wildcard: `| _ => default`
- [ ] No trailing commas in records/lists
- [ ] Use `func` not `fn`, `function`, `def`
- [ ] Use `=>` in pattern match, not `:` or `->`
- [ ] No circular imports
- [ ] State threading (no global mutable state)

## Comprehensive Example: HTTP + JSON + State

```ailang
module benchmark/solution

import "std/io" (println)
import "std/json" (decode, encode)

-- Type definitions
type ApiResponse = {status: string, count: int}
type ProcessState = {total: int, errors: int}

-- HTTP helper
export func fetchJson(url: string) -> Result[ApiResponse, string] ! {Net, IO} {
  let headers = [{name: "Accept", value: "application/json"}]
  match httpRequest(url, "GET", headers, "") {
    | Ok(resp) => {
        println("HTTP " ++ show(resp.status));
        match decode(resp.body) {
          | Ok(json) => Ok({status: "ok", count: 42})  -- Parse JSON
          | Err(e) => Err("JSON parse failed: " ++ e)
        }
      }
    | Err(e) => Err("HTTP failed: " ++ e)
  }
}

-- Process multiple URLs with state threading
export func processUrls(urls: List[string], state: ProcessState) -> ProcessState ! {Net, IO} {
  match urls {
    | [] => state
    | ::(url, rest) => {
        match fetchJson(url) {
          | Ok(resp) => processUrls(rest, {state | total: state.total + resp.count})
          | Err(e) => {
              println("Error: " ++ e);
              processUrls(rest, {state | errors: state.errors + 1})
            }
        }
      }
  }
}

-- Entry point
export func main() -> () ! {Net, IO} {
  let urls = ::("https://api.example.com/1", ::("https://api.example.com/2", []))
  let initialState = {total: 0, errors: 0}
  let finalState = processUrls(urls, initialState)
  println("Total: " ++ show(finalState.total) ++ ", Errors: " ++ show(finalState.errors))
}
```

## What DOESN'T WORK

❌ Custom type classes (built-in only: Num, Eq, Ord, Show)
❌ Loops, mutation, global state (use recursion + state threading)
❌ User-defined effects (stdlib effects only)
❌ Implicit conversions (use `intToFloat`, `floatToInt`)
❌ List comprehensions (use `map`, `filter`)
❌ String interpolation (use `++` concatenation)
❌ Tuple syntax (use records or ADTs)
