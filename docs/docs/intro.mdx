# AILANG: AI-First Programming Language

AILANG is a deterministic, effect-typed functional programming language built as a safe target for AI-generated programs.

AILANG {STABLE_RELEASE} ships a stable core — language, effects, modules — with APIs that may still evolve in pre-1.0 minor releases. The [Stability Promise](/docs/reference/stability) defines which syntax, stdlib, CLI, package (manifest, lockfile, registry), and hosted MCP tool surface is guaranteed across the `1.x` line (Stable / Experimental / Internal tiers).

## What Makes AILANG Different

![AILANG Symbolic Kernel Loop](/img/diagrams/ailang-kernel-loop.svg)

| Capability | What It Gives You |
|---|---|
| **Pure Functional Core** | Deterministic evaluation, immutable values, recursion instead of loops |
| **Algebraic Effects** | Side effects declared in types (`! {IO, FS, Net, AI}`) with `--caps` and `@limit=N` budgets |
| **Z3-Verified Contracts** | Static SMT proofs for `requires` / `ensures` via `ailang verify` with AILANG counterexamples |
| **IFC Taint Labels** | Compile-time `T<label>` sources, `T{not LABEL}` sinks, and auditable `! {Declassify}` sanitizers |
| **Modern Ergonomics** | `|>` pipes, `deriving (Json)`, `let x = expr?`, typed holes `_?`/`?name`, `ailang inspect`, `check --fix` |
| **Two Aligned Engines** | Reference evaluator (spec oracle) + `--bytecode` VM (~40× faster on pure code) + browser WASM |

  <Icon name="info" inline /> **Field positioning:** AILANG combines the *Verification* camp (Z3 contracts + effect rows) and the *Orchestration* camp (`std/ai` typed effect, coordinator, MCP). See [Three Camps Comparison](/docs/guides/three-camps-comparison).

## Core Language Surface ({STABLE_RELEASE})

- <CheckIcon inline size={14} /> **Type System & Records** — [Hindley-Milner inference](/docs/reference/language-syntax#type-inference), type classes (`Num`, `Eq`, `Ord`, `Show`), and row-polymorphic records (`{name: string | r}`)
- <CheckIcon inline size={14} /> **ADTs & Exhaustive Pattern Matching** — nominal types, constructors, tuples, lists, records, guards, and unbraced multi-statement arms
- <CheckIcon inline size={14} /> **Effect System & Budgets** — `IO`, `FS`, `Clock`, `Net` (HTTPS-only, private-IP blocked), `AI`, `SharedMem`, and `Declassify`
- <CheckIcon inline size={14} /> **Tooling Loop** — `ailang inspect --format=agent`, `ailang check --fix`, `ailang lsp`, `ailang test` (inline + property tests), `ailang verify`, and interactive REPL

See [Implementation Status](/docs/reference/implementation-status), [Why 1.0](/docs/why-1-0), and the [Roadmap](/docs/roadmap) for current status and `1.x` plans.
