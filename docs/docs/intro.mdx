# AILANG: AI-First Programming Language

Welcome to the official documentation for AILANG, a deterministic, effect-typed programming language designed as a safe target for AI-generated programs.

AILANG {STABLE_RELEASE} ships a stable core — language, effects, modules, codegen — with APIs that may still evolve in pre-1.0 minor releases.

<div className="callout-box">
  <Icon name="zap" inline /> **New to AILANG?** Read our [Vision](/docs/vision) to understand why AILANG exists and what makes it different from other programming languages.
</div>

## What is AILANG?

AILANG is a pure functional programming language designed for AI-assisted development. Explicit effects, structured traces, and deterministic execution make AI-generated code easier to debug and verify.

Key features:

- <Icon name="zap" inline /> **Pure Functional Core**: Deterministic evaluation, referentially transparent
- <Icon name="target" inline /> **Algebraic Effects**: Side effects declared in types (`! {IO, FS, Net}`)—constrains what code *can* do
- <Icon name="code" inline /> **Structured Traces**: Effect calls logged with typed inputs/outputs for debugging
- <Icon name="brain" inline /> **Pattern Matching**: ADTs with exhaustiveness checking catch invalid states at compile time
- <Icon name="rocket" inline /> **Inline Tests**: Machine-readable specs that travel with code
- <Icon name="bot" inline /> **Go Codegen**: Compile to native performance with full type safety

### <CheckIcon size={18} /> Core Features

- <CheckIcon inline size={14} /> **Recursion** - Self-recursion, mutual recursion, with stack overflow protection
- <CheckIcon inline size={14} /> **Block Expressions** - Multi-statement blocks with proper scoping
- <CheckIcon inline size={14} /> **Records** - Record literals, field access, subsumption
- <CheckIcon inline size={14} /> **Type System** - [Hindley-Milner inference](/docs/reference/language-syntax#type-inference) with type classes (Num, Eq, Ord, Show)
- <CheckIcon inline size={14} /> **Pattern Matching** - Constructors, tuples, lists, wildcards, guards
- <CheckIcon inline size={14} /> **Module System** - Cross-module imports, entrypoint execution
- <CheckIcon inline size={14} /> **Effect System** - IO, FS, Clock, Net, Declassify with capability-based security
  - **Clock Effect**: Monotonic time, sleep, deterministic mode
  - **Net Effect**: HTTP GET/POST with DNS rebinding prevention, IP blocking
  - **Declassify Effect**: Marks functions that lower an [IFC label](/docs/guides/ifc-labels) — every label change is auditable
- <CheckIcon inline size={14} /> **Inline Tests** - Test pure functions directly in code, `ailang test`
- <CheckIcon inline size={14} /> **REPL** - Full type checking, command history, tab completion
- <CheckIcon inline size={14} /> **Lambda Calculus** - First-class functions, closures, currying

### <Icon name="wrench" size={18} /> Recent Additions ({STABLE_RELEASE})

- <CheckIcon inline size={14} /> **IFC Labels (v0.16.0)** - Information-flow control at the type system. `T<label>` marks tainted sources; `T{not LABEL}` marks sinks that refuse them. Implements the language-feature half of Erik Meijer's [Guardians of the Agents](https://cacm.acm.org/practice/guardians-of-the-agents/) (CACM Jan 2026) — see the [IFC labels guide](/docs/guides/ifc-labels) and the [prompt-injection benchmark](https://github.com/sunholo-data/ailang/tree/dev/benchmarks/prompt_injection)
- <CheckIcon inline size={14} /> **Tiered Eval Suite (v0.14.0)** - `smoke / core / stretch / vision` tiers with a 12-tag taxonomy; Core tier is the headline AILANG-vs-Python metric (87.3% vs 81.0% on v0.12.0 baseline)
- <CheckIcon inline size={14} /> **List-only `++` (v0.13.0)** - String concatenation now goes through `"${...}"` interpolation, `concat([...])`, or `join(sep, xs)` — clearer error messages, ~82 fewer lines of compiler heuristics
- <CheckIcon inline size={14} /> **Three-tier OTEL Tracing (v0.12.0)** - `--trace-tier off|standard|deep` with span budgets and `trace.truncated` rollups
- <CheckIcon inline size={14} /> **New Stdlib Modules (v0.12.0)** - `std/gzip`, `std/tar`, plus 6.6× XLSX runtime speedup

### <Icon name="rocket" size={18} /> Roadmap

## Design Philosophy

AILANG is built on several key principles:

1. <Icon name="target" inline /> **Explicit Over Implicit**: All effects and dependencies are visible in types
2. <Icon name="check" inline /> **Debuggability by Construction**: Structured traces and effect boundaries make errors easy to localize
3. <Icon name="bot" inline /> **AI-Optimized**: Constrained syntax and explicit effects narrow the search space for valid code
4. <Icon name="zap" inline /> **Deterministic**: Same input always produces same output, enabling replay and caching
5. <Icon name="info" inline /> **Traceable**: Effect calls logged with typed inputs/outputs for structured debugging
