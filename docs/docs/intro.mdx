# AILANG: AI-First Programming Language

Welcome to the official documentation for AILANG, an experimental programming language designed from the ground up for AI-assisted software development.

## What is AILANG?

AILANG is a pure functional programming language that makes AI assistance a first-class citizen. It features:

- <Icon name="zap" inline /> **Pure Functional Programming**: Immutable data and explicit effects
- <Icon name="target" inline /> **Algebraic Effects System**: Track and control side effects in the type system
- <Icon name="code" inline /> **Type Classes**: Num, Eq, Ord, Show with dictionary-passing semantics
- <Icon name="brain" inline /> **Pattern Matching**: Algebraic data types with exhaustiveness checking
- <Icon name="rocket" inline /> **Auto-Import Prelude**: Zero imports needed for type classes and comparisons
- <Icon name="bot" inline /> **AI-Optimized Design**: Generate structured execution traces for model training

## Quick Example

```typescript
-- Module with effects (v0.3.0)
module examples/hello

import std/io (println)
import std/net (httpGet)

-- Recursive factorial function
export func factorial(n: int) -> int {
  if n <= 1 then 1 else n * factorial(n - 1)
}

-- Function with multiple effects
export func main() -> () ! {IO, Net} {
  println("Factorial of 5 is:");
  println(show(factorial(5)));

  let response = httpGet("https://api.example.com/data");
  println(response)
}
```

Run with: `ailang run --caps IO,Net --entry main examples/hello.ail`

## Current Status: v0.3.8 (October 2025)

AILANG v0.3.8 is now available with multi-line ADT parser fixes and operator lowering improvements! Check the [implementation status](/docs/reference/implementation-status) for complete details.

### <CheckIcon size={18} /> Working Features (v0.3.8)

- <CheckIcon inline size={14} /> **Recursion** - Self-recursion, mutual recursion, with stack overflow protection
- <CheckIcon inline size={14} /> **Block Expressions** - Multi-statement blocks with proper scoping
- <CheckIcon inline size={14} /> **Records** - Record literals, field access, subsumption
- <CheckIcon inline size={14} /> **Type System** - Hindley-Milner inference with type classes (Num, Eq, Ord, Show)
- <CheckIcon inline size={14} /> **Pattern Matching** - Constructors, tuples, lists, wildcards, guards
- <CheckIcon inline size={14} /> **Module System** - Cross-module imports, entrypoint execution
- <CheckIcon inline size={14} /> **Effect System** - IO, FS, Clock, Net with capability-based security
  - **Clock Effect**: Monotonic time, sleep, deterministic mode
  - **Net Effect**: HTTP GET/POST with DNS rebinding prevention, IP blocking
- <CheckIcon inline size={14} /> **REPL** - Full type checking, command history, tab completion
- <CheckIcon inline size={14} /> **Lambda Calculus** - First-class functions, closures, currying

### <Icon name="wrench" size={18} /> Planned Features (v0.4.0+)

- <Icon name="idea" inline size={14} /> **Pattern Guards** - Boolean conditions in pattern matching
- <Icon name="idea" inline size={14} /> **Error Propagation** - `?` operator for Result types
- <Icon name="idea" inline size={14} /> **Typed Quasiquotes** - Safe metaprogramming with compile-time validation
- <Icon name="idea" inline size={14} /> **CSP Concurrency** - Channel-based communication with session types
- <Icon name="idea" inline size={14} /> **AI Training Export** - Execution trace collection (v1.0+)

## Design Philosophy

AILANG is built on several key principles:

1. <Icon name="target" inline /> **Explicit Over Implicit**: All effects and dependencies are visible in types
2. <Icon name="check" inline /> **Correctness by Construction**: Make invalid states unrepresentable
3. <Icon name="bot" inline /> **AI-Friendly**: Every language feature considers AI tooling needs
4. <Icon name="zap" inline /> **Deterministic**: Same input always produces same output
5. <Icon name="info" inline /> **Traceable**: Complete execution history for debugging and training
