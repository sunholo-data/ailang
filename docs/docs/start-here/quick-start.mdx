# I'm new — get me started

Pick the path that fits how you learn.

## Run something in 5 minutes (no install)

- <Icon name="play" inline /> **[Playground](/docs/playground)** — run AILANG in your browser via WebAssembly.
- <Icon name="book" inline /> **[Examples Gallery](/docs/examples)** — runnable, annotated programs from the repo.
- <Icon name="globe" inline /> **[Live Demos](/docs/demos)** — 9 in-browser demos (Z3 verification, DocParse, streaming, safe AI agents).

## Install and write your first module (15 minutes)

- <Icon name="rocket" inline /> **[Getting Started](/docs/guides/getting-started)** — install the CLI, write your first `.ail` module, and learn `|>`, `deriving (Json)`, and `expr?`.
- <Icon name="code" inline /> **[Module Execution](/docs/guides/module_execution)** — how `module`, `import`, `export func main()`, and `ailang inspect` work together.
- <Icon name="wrench" inline /> **[Editor Setup](/docs/guides/editor-setup)** & **[LSP & Quick-Fixes](/docs/guides/lsp)** — VS Code, Vim, JetBrains, and `ailang lsp`.

## Understand the design (deep dive)

- <Icon name="target" inline /> **[Why AILANG](/docs/why-ailang)** — 2-minute pitch, Python/Go/TS comparison, and LoCoBench research.
- <Icon name="shield" inline /> **[Why 1.0](/docs/why-1-0)** — stability contract and honest limits.
- <Icon name="brain" inline /> **[Vision](/docs/vision)** — symbolic reasoning kernel and two-level traces.
- <Icon name="zap" inline /> **[The Effect System](/docs/reference/effects)** & **[Why AILANG Has No Loops](/docs/reference/no-loops)**.
