# AI API Integration Examples

AILANG provides first-class support for calling AI APIs with HTTP headers, JSON encoding, and structured error handling.

## Overview

**Features:**
- ✅ Custom HTTP headers (Authorization, API keys, etc.)
- ✅ JSON encoding with type-safe ADT construction
- ✅ Result-based error handling
- ✅ Security features (header validation, HTTPS enforcement)
- ✅ Support for OpenAI, Anthropic, Google, and other AI APIs

## JSON Encoding

AILANG provides a type-safe JSON ADT for constructing JSON payloads:

### Json ADT

```ailang
type Json =
  | JNull                                      -- null
  | JBool(bool)                                -- true/false
  | JNumber(float)                             -- 3.14, 1e3, 42.0
  | JString(string)                            -- "hello"
  | JArray(List[Json])                         -- [1, 2, 3]
  | JObject(List[{key: string, value: Json}])  -- {"a": 1}
  | JInt(int)                                  -- 42 (exact, any int64)
```

`decode` gives `JInt` for an integer literal that fits int64 and `JNumber` for every other number.

### Convenience Helpers

```ailang
import std/json (jn, jb, jnum, jint, js, ja, jo, kv, encode)

func jsonPrimitivesDemo() -> string {
  let _n = jn();            -- JNull
  let _b = jb(true);        -- JBool(true)
  let _f = jnum(42.5);      -- JNumber(42.5)
  let _i = jint(42);        -- JInt(42)
  let _s = js("hello");     -- JString("hello")
  let _arr = ja([jnum(1.0), jnum(2.0)]);
  let _obj = jo([kv("x", jnum(1.0))]);
  encode(jo([kv("name", js("Alice"))]))  -- "{\"name\":\"Alice\"}"
}
```

### Complex Example

```ailang
import std/json (jnum, js, ja, jo, kv, encode)

func buildApiRequest() -> string {
  let request = jo([
    kv("model", js("gpt-4")),
    kv("temperature", jnum(0.7)),
    kv("messages", ja([
      jo([
        kv("role", js("system")),
        kv("content", js("You are a helpful assistant"))
      ]),
      jo([
        kv("role", js("user")),
        kv("content", js("Hello!"))
      ])
    ])),
    kv("functions", ja([
      jo([
        kv("name", js("get_weather")),
        kv("parameters", jo([
          kv("type", js("object")),
          kv("properties", jo([
            kv("location", jo([kv("type", js("string"))]))
          ]))
        ]))
      ])
    ]))
  ]);
  encode(request)
}
```

## HTTP Request Function

### Signature

`std/net.httpRequest` has type `(string, string, [{name: string, value: string}], string) -> Result[HttpResponse, NetError] ! {Net}`.

### Types

```ailang
type HttpResponse = {
  status: int,
  headers: [{name: string, value: string}],
  body: string,
  ok: bool  -- true if status 200-299
}

type NetError =
  | Transport(string)      -- Network/connection error
  | DisallowedHost(string) -- Domain not in allowlist
  | InvalidHeader(string)  -- Blocked header name
  | BodyTooLarge(string)   -- Response > 5MB
```

### Error Handling

```ailang
import std/io (println)
import std/net (httpRequest, Transport, DisallowedHost, InvalidHeader, BodyTooLarge)

func sendRequest(url: string, headers: [{name: string, value: string}], body: string) -> string ! {Net, IO} {
  match httpRequest("POST", url, headers, body) {
    Ok(resp) =>
      if resp.ok then resp.body
      else {
        println("HTTP error: ${show(resp.status)}");
        ""
      },
    Err(err) => match err {
      Transport(msg) => { println("Network: ${msg}"); "" },
      DisallowedHost(host) => { println("Blocked: ${host}"); "" },
      InvalidHeader(name) => { println("Invalid header: ${name}"); "" },
      BodyTooLarge(size) => { println("Too large: ${show(size)}"); "" },
      _ => { println("Request error"); "" }
    }
  }
}
```

## Security Features

### 1. Header Validation

**Blocked headers** (hop-by-hop, dangerous):
- `Connection`, `Proxy-Connection`, `Keep-Alive`
- `Transfer-Encoding`, `Upgrade`, `Trailer`, `TE`
- `Host` (prevents Host header injection)
- `Accept-Encoding` (prevents decompression issues)
- `Content-Length` (calculated automatically)

```ailang
-- ✅ Allowed
let headers = [
  {name: "Authorization", value: "Bearer token"},
  {name: "Content-Type", value: "application/json"},
  {name: "User-Agent", value: "MyApp/1.0"}
]

-- ❌ Blocked at runtime (returns Err(InvalidHeader(...)))
let badHeaders = [
  {name: "Connection", value: "close"},
  {name: "Host", value: "evil.com"}
]
```

### 2. Cross-Origin Authorization Stripping

Authorization headers are automatically removed on cross-origin redirects (e.g., an initial request to `api.example.com` redirecting to `cdn.example.com`).

### 3. Method Whitelist

`httpRequest` accepts standard HTTP methods (`GET`, `POST`, etc.) and validates headers and URLs:

```ailang
import std/net (httpRequest, HttpResponse, NetError)

func fetchGet(url: string, headers: [{name: string, value: string}]) -> Result[HttpResponse, NetError] ! {Net} =
  httpRequest("GET", url, headers, "")

func fetchPost(url: string, headers: [{name: string, value: string}], body: string) -> Result[HttpResponse, NetError] ! {Net} =
  httpRequest("POST", url, headers, body)
```

### 4. Other Security Features

- ✅ HTTPS enforced (http:// requires `--net-allow-http` flag)
- ✅ DNS rebinding prevention
- ✅ Private IP blocking (localhost, 10.x, 192.168.x, 172.16-31.x)
- ✅ Body size limit (5MB default)
- ✅ Domain allowlist support
- ✅ Redirect validation (max 5 redirects)

## Common Patterns

### 1. Retry on Failure

```ailang
import std/io (println)
import std/net (httpRequest, Transport)

func callWithRetry(url: string, body: string, retries: int) -> string ! {Net, IO} {
  match httpRequest("POST", url, [], body) {
    Ok(resp) => resp.body,
    Err(Transport(msg)) =>
      if retries > 0 then {
        println("Retrying...");
        callWithRetry(url, body, retries - 1)
      } else "Failed after retries: ${msg}",
    Err(other) => show(other)  -- Don't retry non-transient errors
  }
}
```

### 2. Response Parsing

```ailang
-- JSON decoding is available via std/json: import std/json (decode, encode).
func extractContent(jsonBody: string) -> string ! {} {
  jsonBody
}
```

### 3. Streaming Responses

For token-by-token streaming responses, see the [AI Token Streaming recipe](/docs/recipes/ai-token-streaming) (`std/ai/streaming` and `std/stream`).

## Troubleshooting

### "InvalidHeader" Error

```
Error: Err(InvalidHeader("connection"))
```

**Cause:** Attempting to use a blocked header
**Solution:** Remove hop-by-hop headers (Connection, Transfer-Encoding, etc.)

### "DisallowedHost" Error

```
Error: Err(DisallowedHost("evil.com"))
```

**Cause:** Domain not in allowlist (if configured)
**Solution:** Add domain to allowlist or remove allowlist restriction

### "Transport" Error with TLS

```
Error: Err(Transport("tls: certificate verify failed"))
```

**Cause:** Invalid TLS certificate
**Solution:** Check the API endpoint URL is correct

### HTTP 401 Unauthorized

```
HTTP error: 401
```

**Cause:** Invalid or missing API key
**Solution:** Verify your API key is correct and properly formatted

## API-Specific Examples

### Google Gemini

```ailang
import std/json (js, ja, jo, kv, encode)
import std/net (httpRequest)

func chatGemini(prompt: string, apiKey: string) -> string ! {Net} {
  let url = "https://generativelanguage.googleapis.com/v1/models/gemini-2.5-flash:generateContent?key=${apiKey}";
  let headers = [{name: "Content-Type", value: "application/json"}];
  let body = encode(
    jo([
      kv("contents", ja([
        jo([kv("parts", ja([jo([kv("text", js(prompt))])]))])
      ]))
    ])
  );

  match httpRequest("POST", url, headers, body) {
    Ok(resp) => resp.body,
    Err(err) => show(err)
  }
}
```

### Generic REST API

```ailang
import std/json (Json, encode)
import std/net (httpRequest)

func callAPI(endpoint: string, payload: Json, apiKey: string) -> string ! {Net} {
  let headers = [
    {name: "Authorization", value: "Bearer ${apiKey}"},
    {name: "Content-Type", value: "application/json"}
  ];

  match httpRequest("POST", endpoint, headers, encode(payload)) {
    Ok(resp) => resp.body,
    Err(err) => show(err)
  }
}
```
