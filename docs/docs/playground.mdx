## Quick Examples

### Basic Arithmetic
```ailang repl
1 + 2
10 * 5
42.0 / 2.0
```

### Lambda Functions
AILANG is a functional language at heart:
```ailang repl
(\x. x * 2)(21)
```

### Let Bindings
Define and use variables:
```ailang repl
let double = \x. x * 2 in double(21)
```

### Higher-Order Functions
Compose and apply functions:
```ailang repl
let double = \x. x * 2 in
let triple = \x. x * 3 in
double(5) + triple(4)
```

### Type Inference
Check the type of any expression:
```ailang repl
:type \x. \y. x + y
```

### Pattern Matching
Work with tuples:
```ailang repl
let first = \pair. match pair with | (a, b) -> a in first((1, 2))
```

## REPL Commands

| Command | Description |
|---------|-------------|
| `:help` | Show all available commands |
| `:type <expr>` | Display the inferred type of an expression |
| `:instances` | Show available type class instances |
| `:reset` | Clear the environment and start fresh |

## Browser Limits & Next Steps

- **Powered by WebAssembly**: Full AILANG interpreter + stdlib (`GOOS=js GOARCH=wasm`, `:import std/prelude` auto-loaded).
- **Security sandbox**: `FS` and `Net` effects are disabled in the browser REPL; install the CLI for full capabilities.
