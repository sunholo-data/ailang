# AILANG Examples

Learn AILANG through interactive examples. Each example demonstrates a key feature with **real working code** from the repository.

## <Icon name="zap" /> Quick Start Examples

### Hello World

The simplest AILANG program with I/O effects:

<CodeBlock language="typescript" title="examples/runnable/hello.ail">
  {HelloExample}
</CodeBlock>

<small>[View source on GitHub](https://github.com/sunholo-data/ailang/blob/dev/examples/runnable/hello.ail)</small>

**Run it:**
```bash
ailang run --caps IO examples/runnable/hello.ail
```

**Key concepts:**
- <CheckIcon inline /> `! {IO}` declares the function performs I/O
- <CheckIcon inline /> `println` is imported from `std/io`
- <CheckIcon inline /> `--caps IO` grants I/O capability at runtime

### Recursion & Pure Functions

AILANG uses recursion instead of loops for deterministic control flow:

<CodeBlock language="typescript" title="examples/runnable/recursion_factorial.ail">
  {FactorialExample}
</CodeBlock>

<small>[View source on GitHub](https://github.com/sunholo-data/ailang/blob/dev/examples/runnable/recursion_factorial.ail)</small>

**Run it:**
```bash
ailang run --caps IO examples/runnable/recursion_factorial.ail
```

**Note:** The `main` function is the default entrypoint. This example prints factorial results using IO.

**Key concepts:**
- <CheckIcon inline /> `factorial` is **pure** (no effects declared)
- <CheckIcon inline /> Recursion replaces loops for deterministic reasoning
- <CheckIcon inline /> `show()` converts int to string for printing

## <Icon name="code" /> Pattern Matching

### Lists & Destructuring

Pattern matching is AILANG's primary control flow mechanism:

<CodeBlock language="typescript" title="examples/runnable/list_sum.ail">
  {ListSumExample}
</CodeBlock>

<small>[View source on GitHub](https://github.com/sunholo-data/ailang/blob/dev/examples/runnable/list_sum.ail)</small>

**Run it:**
```bash
ailang run examples/runnable/list_sum.ail
```

**Output:**
```
(15, 5)
```

**Key concepts:**
- <CheckIcon inline /> `INil` matches empty list
- <CheckIcon inline /> `ICons(head, tail)` destructures list
- <CheckIcon inline /> `letrec` enables recursive function definitions
- <CheckIcon inline /> Exhaustive matching required (compiler enforces)

### Effect Polymorphism

Functions can be generic over effects. This allows writing reusable code that works with any combination of capabilities:

```typescript
-- Effect row polymorphism: {IO | e} means "IO plus any other effects"
-- This allows functions to compose while preserving effect safety
```

**Key concepts:**
- <CheckIcon inline /> Effect rows can be extended with `{IO | e}` syntax
- <CheckIcon inline /> Effect polymorphism enables reusable library functions
- <CheckIcon inline /> Effects compose naturally when calling functions

## <Icon name="play" /> Try It Yourself

### In the Playground

Visit the [Playground](/docs/playground) to run code interactively in your browser.

### With CLI

Install AILANG and run examples locally:

```bash
# Install (macOS Apple Silicon)
curl -L https://github.com/sunholo-data/ailang/releases/latest/download/ailang-darwin-arm64.tar.gz | tar -xz
sudo mv ailang /usr/local/bin/

# Or build from source
git clone https://github.com/sunholo-data/ailang && cd ailang && make install

# Run an example
ailang run --caps IO examples/runnable/hello.ail

# Interactive REPL
ailang repl
```

### From GitHub

Clone the repository for all 97+ examples:

```bash
git clone https://github.com/sunholo-data/ailang
cd ailang

# Run specific examples
ailang run --caps IO examples/runnable/recursion_factorial.ail
```
