# AILANG Examples

Learn AILANG through interactive examples. Each example demonstrates a key feature with working code you can try in the [Playground](/docs/playground).

## <Icon name="zap" /> Quick Start Examples

### Hello World

The simplest AILANG program with I/O effects:

```typescript
module examples/hello

import std/io (println)

fn main() !: IO -> () =
    println("Hello, AILANG!")
```

**Run it:**
```bash
ailang run --caps IO --entry main examples/hello.ail
```

**Key concepts:**
- <CheckIcon inline /> `!: IO` declares the function performs I/O
- <CheckIcon inline /> `println` is imported from `std/io`
- <CheckIcon inline /> `--caps IO` grants I/O capability at runtime

---

### Recursion & Pure Functions

AILANG uses recursion instead of loops for deterministic control flow:

```typescript
-- Factorial: pure function, no effects
fn factorial(n: int) -> int =
    if n <= 1 then 1
    else n * factorial(n - 1)

-- Main: performs I/O
fn main() !: IO -> () =
    println(show(factorial(5)))
```

**Run it:**
```bash
ailang run --caps IO --entry main examples/factorial.ail
```

**Output:**
```
120
```

**Key concepts:**
- <CheckIcon inline /> `factorial` is **pure** (no effects declared)
- <CheckIcon inline /> Recursion replaces loops for deterministic reasoning
- <CheckIcon inline /> `show()` converts int to string for printing

---

## <Icon name="code" /> Pattern Matching

### Lists & Destructuring

Pattern matching is AILANG's primary control flow mechanism:

```typescript
import std/io (println)

-- Sum list using pattern matching
fn sum(list: [int]) -> int =
    match list {
        [] -> 0,
        [head, ...tail] -> head + sum(tail)
    }

fn main() !: IO -> () =
    let numbers = [1, 2, 3, 4, 5];
    println("Sum: " ++ show(sum(numbers)))
```

**Output:**
```
Sum: 15
```

**Key concepts:**
- <CheckIcon inline /> `[]` matches empty list
- <CheckIcon inline /> `[head, ...tail]` destructures list
- <CheckIcon inline /> Exhaustive matching required (compiler enforces)

---

### Algebraic Data Types (ADTs)

Define custom types with multiple constructors:

```typescript
import std/io (println)

type Tree =
    | Leaf(int)
    | Node(Tree, int, Tree)

-- Sum all values in tree
fn sumTree(tree: Tree) -> int =
    match tree {
        Leaf(n) -> n,
        Node(left, value, right) ->
            sumTree(left) + value + sumTree(right)
    }

fn main() !: IO -> () =
    let tree = Node(Leaf(1), 2, Node(Leaf(3), 4, Leaf(5)));
    println("Tree sum: " ++ show(sumTree(tree)))
```

**Output:**
```
Tree sum: 15
```

**Key concepts:**
- <CheckIcon inline /> `type Tree =` defines an ADT with 2 constructors
- <CheckIcon inline /> Pattern matching handles all cases
- <CheckIcon inline /> Compiler ensures exhaustiveness

## <Icon name="target" /> Effect System

### Multiple Effects

Functions can declare multiple effects they perform:

```typescript
import std/io (println)
import std/fs (readFile)
import std/json (decode)

fn loadConfig() !: IO,FS -> Result[string, string] =
    do {
        content <- readFile("config.json");
        println("Loaded config file");
        return Ok(content)
    }

fn main() !: IO,FS -> () =
    match loadConfig() {
        Ok(content) -> println("Config: " ++ content),
        Err(e) -> println("Error: " ++ e)
    }
```

**Run it:**
```bash
ailang run --caps IO,FS --entry main examples/config.ail
```

**Key concepts:**
- <CheckIcon inline /> `!: IO,FS` declares both I/O and filesystem effects
- <CheckIcon inline /> `do` blocks sequence effectful operations
- <CheckIcon inline /> `Result[T,E]` type for error handling

---

### Effect Polymorphism

Functions can be generic over effects:

```typescript
-- Works with any effect row
fn log[e](message: string) !: {IO | e} -> () =
    println("[LOG] " ++ message)

-- Calls log while also reading files
fn processFile(path: string) !: IO,FS -> () =
    do {
        log("Reading file: " ++ path);
        content <- readFile(path);
        log("File loaded")
    }
```

**Key concepts:**
- <CheckIcon inline /> `!: {IO | e}` means "IO plus whatever effects the caller has"
- <CheckIcon inline /> Effect polymorphism enables reusable functions
- <CheckIcon inline /> Effect rows compose naturally

## <Icon name="brain" /> Type System

### Type Inference

AILANG infers types automatically using Hindley-Milner:

```typescript
import std/io (println)

-- No type annotations needed!
fn double(x) = x * 2

fn main() !: IO -> () =
    let result = double(21);
    println(show(result))  -- Prints: 42
```

**Key concepts:**
- <CheckIcon inline /> Type inference works across function boundaries
- <CheckIcon inline /> Explicit annotations optional but recommended
- <CheckIcon inline /> `:type` command in REPL shows inferred types

---

### Records & Subsumption

Records are structural types with width subtyping:

```typescript
import std/io (println)

type Person = { name: string, age: int }

fn greet(person: Person) !: IO -> () =
    println("Hello, " ++ person.name)

fn main() !: IO -> () =
    let employee = { name: "Alice", age: 30, role: "Engineer" };
    greet(employee)  -- OK! employee has all required fields
```

**Key concepts:**
- <CheckIcon inline /> Records support structural typing
- <CheckIcon inline /> Width subtyping: `{a, b, c}` ⊆ `{a, b}`
- <CheckIcon inline /> Field access: `record.field`

## <Icon name="box" /> JSON & HTTP

### JSON Parsing

Parse and work with JSON data:

```typescript
import std/io (println)
import std/json (decode)

fn main() !: IO -> () =
    let jsonString = "{\"name\": \"AILANG\", \"version\": \"0.3.14\"}";

    match decode(jsonString) {
        Ok(json) ->
            match json {
                Object(fields) ->
                    match fields["name"] {
                        Some(String(name)) -> println("Name: " ++ name),
                        _ -> println("Name not found")
                    },
                _ -> println("Not an object")
            },
        Err(e) -> println("Parse error: " ++ e)
    }
```

**Key concepts:**
- <CheckIcon inline /> `decode` returns `Result[Json, string]`
- <CheckIcon inline /> Pattern match on JSON structure
- <CheckIcon inline /> Safe access to nested fields

---

### HTTP Requests

Make HTTP requests with the Net effect:

```typescript
import std/io (println)
import std/net (httpGet)

fn main() !: IO,Net -> () =
    match httpGet("https://api.github.com/repos/sunholo-data/ailang") {
        Ok(response) ->
            println("Status: " ++ show(response.status)),
        Err(e) ->
            println("Request failed: " ++ e)
    }
```

**Run it:**
```bash
ailang run --caps IO,Net --entry main examples/http_get.ail
```

**Key concepts:**
- <CheckIcon inline /> `!: IO,Net` declares network capability
- <CheckIcon inline /> `httpGet` returns `Result[Response, string]`
- <CheckIcon inline /> DNS rebinding protection built-in

## <Icon name="rocket" /> Advanced Examples

### Higher-Order Functions

Functions are first-class values:

```typescript
import std/io (println)

fn map(f, list) =
    match list {
        [] -> [],
        [x, ...xs] -> [f(x), ...map(f, xs)]
    }

fn main() !: IO -> () =
    let numbers = [1, 2, 3, 4, 5];
    let doubled = map(\x -> x * 2, numbers);
    println(show(doubled))  -- [2, 4, 6, 8, 10]
```

**Key concepts:**
- <CheckIcon inline /> `\x -> x * 2` is a lambda function
- <CheckIcon inline /> Functions can be passed as arguments
- <CheckIcon inline /> Closures capture environment

---

### Mutual Recursion

Multiple functions can call each other:

```typescript
import std/io (println)

fn isEven(n: int) -> bool =
    if n == 0 then true
    else isOdd(n - 1)

fn isOdd(n: int) -> bool =
    if n == 0 then false
    else isEven(n - 1)

fn main() !: IO -> () =
    println("5 is odd: " ++ show(isOdd(5)))  -- true
```

**Key concepts:**
- <CheckIcon inline /> Functions can reference each other
- <CheckIcon inline /> Stack overflow protection included
- <CheckIcon inline /> Deterministic evaluation order
