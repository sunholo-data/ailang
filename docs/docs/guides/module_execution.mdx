## Execution Pipeline

```mermaid
flowchart LR
    A["Source (.ail)"] --> B["Parse & Check"]
    B --> C["Elaborate Core ANF"]
    C --> D["Load Imports & iface"]
    D --> E["Resolve --entry"]
    E --> F["Execute (Eval or --bytecode VM)"]
```

## Quick Start

```bash
# Inspect module exports, effects, and contracts without reading source
ailang inspect --format=agent examples/runnable/hello.ail
ailang inspect --json --exports-only examples/runnable/hello.ail

# Run default main() entrypoint
ailang run --caps IO --entry main examples/runnable/hello.ail

# Run a named 1-arg entrypoint with JSON input (wrap multi-field inputs in a record)
ailang run --caps IO --entry process --args-json '{"input": "data", "count": 5}' examples/docs/module_process_record.ail
```

## Module Rules & Entrypoints

- **Canonical `module` header:** First line must match the repo-relative path (`examples/demo.ail` -> `module examples/demo`). Use `--relax-modules` during local prototyping.
- **Exported functions only:** Entrypoints must be declared `export func` (or `export pure func`), taking **0 or 1 parameters**. Wrap multi-field inputs in a record:

<CodeBlock language="ailang" title="examples/docs/module_add_record.ail">
  {ModuleAddRecord}
</CodeBlock>

```bash
ailang run --entry add --args-json '{"x": 10, "y": 32}' examples/docs/module_add_record.ail
```

- **Return values:** Non-unit values print automatically to stdout; `()` (Unit) prints nothing unless you call `println` (`! {IO}`).
- **Encapsulation:** Private bindings (`func helper()`) stay module-local.

## Explicit, Non-Transitive Imports

Imports in AILANG are **never transitive** — if module A imports B and B uses `std/fs`, A's execution context only grants what A declares and imports explicitly.

| Form | Syntax | Resolution |
|---|---|---|
| Standard library | `import std/list (map, filter)` | Bundled stdlib (`ailang docs std/list`) |
| Module alias | `import std/string as Str` | Qualified `Str.length(s)` |
| Symbol alias | `import std/list (length as listLen)` | Resolves name collisions (`Str.length` vs `listLen`) |
| Intra-package sibling | `import ./types (Config)` | Same package without needing `ailang.lock` first |
| External package | `import pkg/vendor/name/mod (fn)` | Resolved via `ailang.lock` |

:::note `export import` re-exports
`export import mod (sym)` makes the listed names part of this module's exports, with the original's identity. A module can move behind such a facade without breaking its importers. See [Re-exports](/docs/reference/language-syntax#re-exports-export-import).
:::

```ailang file=math/utils.ail
module math/utils

export pure func double(x: int) -> int = x * 2
```

```ailang file=app/main.ail
module app/main

import std/io (println)
import math/utils (double)

export func main() -> () ! {IO} {
  println(show(double(21)))
}
```

## Capabilities, CLI Flags & `ailang inspect`

| Command / Flag | Purpose |
|---|---|
| `ailang inspect --format=agent <path>` | Emit compact semantic X-ray (types, exports, `! {Effects}`, contracts, callees) |
| `ailang inspect --json <path>` | Machine-readable interface JSON for a file or directory |
| `ailang run --caps IO,FS --entry fn file.ail` | Grant runtime capabilities matching declared `! {Effects}` |
| `ailang run --args-json '{"k":1}' file.ail` | Pass JSON payload to 1-arg entrypoint |
| `ailang run --bytecode file.ail` | Execute on the bytecode VM (`--strict-bytecode` fails on evaluator fallback) |
| `ailang run --no-print file.ail` | Suppress automatic printing of non-unit return value |

## Common Errors

| Error | Cause | Fix |
|---|---|---|
| `MOD010` module path mismatch | `module` header doesn't match file path | Rename header to match path, or pass `--relax-modules` |
| `IMP010: symbol not exported` | Missing `export` on type/func or removed alias | Add `export` or check `ailang docs std/<mod>` |
| `PAR_REEXPORT_FORM` | `export import M` without a name list, or with `as` | List the names: `export import M (a, b)` |
| Entrypoint takes 2+ args | CLI `--entry` supports 0 or 1 arg | Wrap parameters in a record and pass `--args-json` |
| `Missing capability: IO` | Program declares `! {IO}` without `--caps IO` | Add `--caps IO` before the file path |
