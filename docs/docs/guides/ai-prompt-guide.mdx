# AI Prompt Guide: Teaching AILANG to Language Models

**Purpose**: This document explains how to use AILANG teaching prompts with AI models.

**KPI**: One of AILANG's key success metrics is **"teachability to AI"** - how easily can an LLM learn to write correct AILANG code from a single prompt?

---

## <Icon name="book" inline /> Canonical Prompt

**The official AILANG teaching prompt is always available via CLI:**

```bash
ailang prompt          # Get current/active prompt
ailang prompt --list   # List all versions
```

This prompt is:
- <CheckIcon inline size={14} /> **Validated through eval benchmarks** - Tested across GPT-5, Gemini 2.5 Pro, Claude Sonnet 4.5

## <Icon name="info" inline /> Quick Reference

**Core Features**:
- <CheckIcon inline size={14} /> Module execution with effects
- <CheckIcon inline size={14} /> Recursion (self-recursive and mutually-recursive)
- <CheckIcon inline size={14} /> Block expressions (`{ stmt1; stmt2; result }`)
- <CheckIcon inline size={14} /> Records (literals + field access + updates)
- <CheckIcon inline size={14} /> Multi-line ADTs `type Tree = | Leaf | Node`
- <CheckIcon inline size={14} /> Record update syntax `{base | field: value}`
- <CheckIcon inline size={14} /> Auto-import std/prelude - No imports needed for comparisons
- <CheckIcon inline size={14} /> Syntactic sugar: `::` cons, `->` function types, `f()` zero-arg calls
- <CheckIcon inline size={14} /> Effects: IO, FS, Clock, Net, Env, AI, SharedMem, SharedIndex
- <CheckIcon inline size={14} /> Type classes, ADTs, pattern matching
- <CheckIcon inline size={14} /> REPL with full type checking

**Known Limitations**:
- See [Implementation Status](/docs/reference/implementation-status) for current limitations
- See [LIMITATIONS.md](https://github.com/sunholo-data/ailang/blob/main/docs/LIMITATIONS.md) for workarounds

**For complete syntax guide**, see the [Current Teaching Prompt](/docs/prompts/current) or use `ailang prompt`

## <Icon name="code" inline /> Using the Prompt

### For AI Code Generation

When asking an AI model (Claude, GPT, Gemini) to write AILANG code, provide the full prompt from `ailang prompt`.

**Example usage**:
```
I need you to write AILANG code to solve this problem: [problem description]

First, read this AILANG syntax guide:
[paste output from: ailang prompt]

Now write the code.
```

### Via CLI (Recommended)

```bash
# Get current/active prompt
ailang prompt

# Get specific version
ailang prompt --version v0.5.11

# List all available versions
ailang prompt --list

# Save to file
ailang prompt > syntax.md
```

### For Eval Benchmarks

The eval harness automatically loads the correct prompt version from `prompts/versions.json`:

```yaml
# benchmarks/example.yml
id: example_task
languages: ["ailang", "python"]
# Prompt version is auto-resolved from prompts/versions.json
task_prompt: |
  Write a program that [task description]
```

See [benchmarks/README.md](https://github.com/sunholo-data/ailang/tree/main/benchmarks) for details.

## <Icon name="wrench" inline /> Contributing Improvements

If you find ways to improve the AILANG teaching prompt:

1. **Test your changes** with the eval harness:
   ```bash
   ailang eval-suite --models gpt5-mini,claude-haiku-4-5
   ```

2. **Measure impact** by comparing success rates

3. **Create new prompt version** in `prompts/` following the versioning system

4. **Document changes** with SHA-256 hash and notes in `prompts/versions.json`

5. **Update active version** in `prompts/versions.json` when ready
