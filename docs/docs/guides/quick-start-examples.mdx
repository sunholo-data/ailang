# Quick Start Examples

Runnable AILANG examples covering core syntax, modern idioms (`|>`, destructuring, `deriving (Json)`, `?` propagation), effects, and tests.

## Prerequisites

Install AILANG and check your setup with [Getting Started](./getting-started):

```bash
ailang --version
```

## Coding Challenges

The `ailang_bootstrap` plugin includes guided challenges (`ask-ai`, `summarize-file`, `ai-debate`, `game-of-life`):

```
/ailang:challenge game-of-life
```

Each challenge directory in [`ailang_bootstrap/challenges`](https://github.com/sunholo-data/ailang_bootstrap/tree/main/challenges) pairs `challenge.md` (prompt) with `solution.ail` (verified reference) and optional `hints.md`.

## Modern Idioms

### 6. Pipes (`|>`) and Unbraced `match`/`if`

```ailang
module docs/pipes_and_unbraced

import std/list (filter, map, foldl)
import std/option (Option, Some, None)

export pure func scorePipeline(scores: [int]) -> int =
  scores
    |> (\xs. filter(\n. n >= 0, xs))
    |> (\xs. map(\n. if n > 100 then 100 else n, xs))
    |> (\xs. foldl(\acc n. acc + n, 0, xs))

export pure func classify(opt: Option[int], bonus: bool) -> int =
  match opt {
    Some(n) =>
      let base = n * 10;
      if bonus then
        let total = base + 5;
        total
      else base,
    None => 0
  }
```

## Tooling Loop: `inspect`, `check --fix`, and REPL

```bash
# X-ray a module's exports, effects, and contracts without reading the whole file
ailang inspect --format=agent examples/runnable/derive_json.ail

# Auto-apply safe mechanical fixes (! {Effects}, ++ -> "${...}", TC_MATCH_002 stubs)
ailang check --fix path/to/file.ail
```

Start an interactive session with `ailang repl`:

```ailang repl
λ[Debug,IO]> 1 + 2
3 :: Int

λ[Debug,IO]> "Hello World"
Hello World :: String

λ[Debug,IO]> let double = \x. x * 2 in double(21)
42 :: Int

λ[Debug,IO]> :type \x. x + x
\x. x + x :: int -> int

λ[Debug,IO]> :quit
```

## CLI Quick Reference

| Command | Description |
|---|---|
| `ailang inspect --format=agent file.ail` | Compact X-ray of types, exports, effects, contracts |
| `ailang check --fix file.ail` | Apply compiler-verified quick-fixes and type-check |
| `ailang verify file.ail` | Prove `requires`/`ensures` contracts with Z3 |
| `ailang test file.ail` | Run inline `tests`, unit `test`, and `property` checks |
| `ailang run --caps CAPS --entry main file.ail` | Execute a module with explicit capabilities |
| `ailang prompt` | Print the current AI teaching prompt |
