## Document Intelligence & Verification

### Document Extractor — [Try it](https://www.sunholo.com/ailang-demos/extractor.html)
`WASM` · `std/ai` · `Contracts`

Upload invoices, receipts, contracts, or bank statements — `std/ai` extracts structured data and AILANG `requires`/`ensures` contracts validate every field across 7 presets.

### DocParse — [Try it](https://www.sunholo.com/ailang-demos/docparse.html)
`WASM` · `std/xml` · `std/zip`

Parse DOCX, PPTX, XLSX, PDF, and images purely in-browser across 10 AILANG modules with 28 structural contracts and zero server round-trips.

### Z3 Verify — [Try it](https://www.sunholo.com/ailang-demos/verify.html)
`Contracts` · `Z3 SMT`

Static contract verification with Z3 across 4 scenarios: cloud billing (12 verified, 2 intentional violations), 48-path access control, room scheduling, and safe arithmetic.

### AI + Contracts — [Try it](https://www.sunholo.com/ailang-demos/contracts-ai.html)
`std/ai` · `Contracts`

Deterministic verification of stochastic AI output: schema-first extraction followed by contract-checked typed results.

## Substrate Smoke Tests (In-Repo)

Technical smoke tests deployed alongside this docs site (`ailang.sunholo.com/demos/...`) to verify low-level WASM substrate primitives:

- **[Cognitive OS — M1 Smoke Test](pathname:///demos/cognitive-os-runtime/index.html)** (`!: {DOM, Msg, Cog}`): 20-assertion suite testing canonical DOM patching, IndexedDB event log replay with FNV-1a verification, and cross-tab `BroadcastChannel` envelopes.
- **[BYO-Key AI Step](pathname:///demos/wasm-step-byo-key/index.html)** (`!: AI`): Exercises `std/ai.step`, `stepWithCache`, and `stepWithStream` via a browser JS handler using your own localStorage API key.
