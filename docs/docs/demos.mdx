## Document Intelligence

### Document Extractor

**[Try it](https://www.sunholo.com/ailang-demos/extractor.html)** | WASM, AI Effect, Contracts

AI-powered extraction with schema detection. Upload invoices, receipts, contracts, or bank statements — AILANG contracts validate every AI extraction result before returning.

**AILANG features demonstrated:**
- <Icon name="bot" inline /> `std/ai` effect for calling LLMs (Gemini)
- <Icon name="shield" inline /> `requires`/`ensures` contract verification
- <Icon name="box" inline /> Full AILANG interpreter compiled to WebAssembly
- 7 demo presets with 3-tier graceful degradation

### DocParse

**[Try it](https://www.sunholo.com/ailang-demos/docparse.html)** | WASM, std/xml, std/zip

Parse DOCX, PPTX, XLSX, PDF, and images entirely in-browser. 10 AILANG modules handle pure deterministic parsing — no server round-trips.

**AILANG features demonstrated:**
- <Icon name="code" inline /> `std/xml` and `std/zip` stdlib modules
- <Icon name="shield" inline /> 28 contracts enforce structural invariants
- <Icon name="box" inline /> WebAssembly execution with zero server dependency
- Handles merged cells, track changes, and multi-format detection

### Z3 Verify

**[Try it](https://www.sunholo.com/ailang-demos/verify.html)** | Contracts, Z3

Static contract verification with the Z3 theorem prover. Watch Z3 mathematically prove correctness or find counterexamples across 4 real-world scenarios.

**AILANG features demonstrated:**
- <Icon name="shield" inline /> `requires`/`ensures` with Z3 backend (`ailang verify`)
- Cloud billing contracts (12 verified, 2 intentional violations)
- Access control with 48 permission paths
- Conference room scheduling with capacity bounds
- Arithmetic contracts (clamping, tax, safe subtraction)

### AI + Contracts

**[Try it](https://www.sunholo.com/ailang-demos/contracts-ai.html)** | AI Effect, Contracts

The core AILANG value proposition in one demo: AI extracts structured data from documents, then AILANG contracts validate every field before returning. Deterministic verification of stochastic AI output.

**AILANG features demonstrated:**
- <Icon name="bot" inline /> AI effect for extraction
- <Icon name="shield" inline /> Contract validation of AI output
- Schema-first extraction with typed results

## Substrate smoke tests

These are **technical demos** that live in this repo (rather than the polished demos hub at sunholo.com). They exercise individual AILANG substrate primitives end-to-end in the browser — useful for verifying the WASM runtime, BYO-key AI bridge, and Cognitive OS effects (`!: {DOM, Msg, Cog}`) work as expected, but not designed for general use. Deployed at `ailang.sunholo.com/demos/...` alongside the docs site.

### Cognitive OS — M1 Smoke Test

**[Try it](/demos/cognitive-os-runtime/)** | `!: {DOM, Msg, Cog}`, event log, byte-identical replay

20-assertion smoke suite for the [M-COG-RUNTIME](https://github.com/sunholo-data/ailang/tree/dev/design_docs/implemented/v0_21_0) substrate. Add panel / update / timeline / reset buttons drive the canonical DOM patch dispatcher directly; capture+verify checks byte-equality across IndexedDB replay; cross-tab BroadcastChannel test confirms the Msg fabric carries Lamport-stamped envelopes between tabs.

**Substrate features exercised:**
- <Icon name="code" inline /> `CognitiveOS._applyPatchDirect` (DOM effect via canonical patches with content-hashed nodeIDs)
- <Icon name="box" inline /> IndexedDB-persisted cognitive event log with canonical (clock, sender) replay order
- <Icon name="shield" inline /> Byte-identical reconstruction verified via FNV-1a content hashing
- Cross-tab Msg fabric over `BroadcastChannel` Web API

The richer, user-facing Cognitive Commons demo (4 personas, sentiment-driven manifesto, multi-tab debating society) builds on this substrate and is deploying soon at [www.sunholo.com/ailang-demos/cognitive-commons](https://www.sunholo.com/ailang-demos/).

### BYO-Key AI Step

**[Try it](/demos/wasm-step-byo-key/)** | `!: AI`, `ai.step` / `stepWithCache` / `stepWithStream`

The three `std/ai` step variants — single-shot, system-prompt caching, streaming — driven directly from the browser. Paste your own Anthropic/OpenRouter/Gemini key (stored in localStorage only); the WASM-resident AILANG module fetches the provider through a JS-injected handler. Demonstrates the BYO-key pattern that other browser demos in this repo build on.

**Substrate features exercised:**
- <Icon name="bot" inline /> `std/ai.step` with three caching/streaming shapes
- <Icon name="box" inline /> AILANG modules loaded into the WASM REPL at runtime via `repl.loadModule`
- BYO-key router: AILANG → JS handler → provider `fetch`

## Building Your Own Demos

AILANG's [WebAssembly integration](/docs/guides/wasm-integration) makes it straightforward to build browser-based demos. The WASM binary includes the full interpreter and all stdlib modules.

Key APIs:
- `loadModule()` — Load AILANG code into the browser
- `setEffectHandler()` — Wire effects to JavaScript callbacks
- `evalAsync()` — Execute AILANG with async effects

See the [WASM Integration Guide](/docs/guides/wasm-integration) for complete API documentation and the [demo source code](https://github.com/sunholo-data/ailang-demos) for reference implementations.
