# Archived Documentation

This directory contains temporary status files, completion reports, and analysis documents that are no longer actively maintained but preserved for historical reference.

## Organization

### 2025-10/ (October 2025)
- **completion_reports/** - Milestone completion summaries and feature completion announcements
  - M-DX1, M-DX4, M-DX8 reports (Developer Experience milestones)
  - M-POLY reports (Monomorphization/polymorphism features)
  - MILESTONE_1/2/3 reports (Agent system milestones)
  - WASM_DEPLOYMENT - WebAssembly deployment completion
  - FINAL_SUMMARY, DOCUMENTATION_CLEANUP_SUMMARY - Documentation work summaries

- **analysis/** - Evaluation results, benchmark analysis, and performance studies
  - AGENT_* - Agent evaluation and benchmark work
  - BENCHMARK_* - Benchmark audit and analysis
  - M-EVAL-HTTP-FIX-FINDINGS - HTTP evaluation fixes
  - NEW_BENCHMARK_TEST_RESULTS, PER_BENCHMARK_TIMEOUT_RESULTS - Test result summaries
  - POST_RELEASE_WORKFLOW_ANALYSIS - Release workflow analysis
  - VISION_BENCHMARK_RESULTS - Vision benchmark results
  - BENCHMARK_COMPARISON_v0.3.9.md - Historical benchmark dashboard (Oct 16, 2025)

- **bug_fixes/** - Bug investigation and fix reports
  - LANG_PLACEHOLDER_FIX - Language placeholder bug fix
  - SELF_REPAIR_DISCOVERY - Self-repair mechanism discovery

### 2025-11/ (November 2025)
- **analysis/** - v0.4.0 failure analysis and bug investigations
  - V0.4.0_AILANG_FAILURE_ANALYSIS - v0.4.0 failure analysis
  - V0.4.0_FAILURE_ROOT_CAUSE_ANALYSIS - Root cause analysis for v0.4.0 issues
  - API_CALL_JSON_FAILURE_ANALYSIS - JSON API call failure analysis

## Preservation Policy

Files are archived by month when they:
- Document completed milestones or features
- Contain temporary status updates or progress reports
- Provide historical analysis or investigation results
- Are no longer actively referenced in current documentation

All files retain their original names with optional version suffixes for clarity.
