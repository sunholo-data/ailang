## Tips

- File extension is `.mbt`
- Entry point is `fn main { ... }` (no parens after `main`, no return type annotation)
- Use `println(...)` for output (auto-appends newline; available without import)
- Use `print(...)` for output without trailing newline
- MoonBit has type inference, ADTs (`enum`), pattern matching (`match`), generics, traits
- String interpolation: `"Hello \{name}"` (note the backslash escape)
- Arrays: `[1, 2, 3]`; lists: `@list.from_array([1, 2, 3])`; maps: `{ "k": "v" }`
- Do NOT use external packages — only the MoonBit core library (`@core`)
- Show types and trait impls for custom output with `derive(Show)` and `println` on a value
