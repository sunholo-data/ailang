## Critical Aver Syntax Reminders

- File extension is `.av` (NOT `.aver`)
- Entry point is `fn main() -> Unit` with INDENTED body (NO braces)
- Effects must be declared: `! [Console.print]` after the signature, before the body
- Use `Console.print("...")` for output (NOT `println`)
- String interpolation: `"value: {x}"` (single braces, NO backslash)
- Constructors are namespaced: `Result.Ok(v)`, `Option.Some(v)`, `Option.None`
- No `if`/`else` — use `match` only
- The last expression in a function body is its return value
