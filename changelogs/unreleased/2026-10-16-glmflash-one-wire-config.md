### Fixed — one wire config for glm-5.3-flash across every harness (cap, effort, routing)

Every glm-5.3-flash pi-vs-motoko A/B compared two different requests. OpenRouter Broadcast (2026-10-16): motoko sent `max_tokens: 32000`, no reasoning effort and the registry's `provider` block; pi sent `max_completion_tokens` ≈ 943k, `reasoning.effort: "high"` and no `provider` block, because the rig's installed `~/.pi/agent/models.json` had drifted from `tools/pi-extensions/models.mission.json` and did not carry the model (pi then uses its own catalogue), and because pi calls OpenRouter with its own client, which AILANG's routing never reaches. motoko hit the 32k cap 27 times on the hard set; pi never did.

- **Registry** (Mark, option A): all five `z-ai/glm-5.3-flash` rows declare `max_output_tokens: 131072` and `reasoning_effort: "high"`. New `TestModels_SameAPINameSameWireBudget` requires rows sharing an api_name to agree on both; four api_names that still disagree (all pi rows at 32000 for a clamp pi 0.85.1 no longer applies) are listed and the list can only shrink.
- **AILANG's OpenRouter client** sends the registry's `reasoning_effort` when a caller sets none (`SetReasoningDefaults`, on Step, StreamStep and Generate), so motoko's runtime — which calls `step` without reasoning options — now carries it. The default goes through the capability gate like a caller's effort; `openrouter / z-ai/glm-5.3-flash / high` is registered as live-verified (1,000+ accepted calls in Broadcast). A caller's own control still wins.
- **pi config**: the canonical glm-5.3-flash entry carries `maxTokens: 131072`, a thinking map that passes `high` through (it mapped every level to null), `compat.openRouterRouting` equal to what AILANG sends, and current pricing. `TestPiModelsConfigMatchesRegistry` now also checks effort and routing; `EffectiveOpenRouterProvider` is pinned equal to the client's `routeFor`.
- **pi preflight**: before an eval run with registry settings, the pi executor reads the `models.json` pi will load (`$PI_CODING_AGENT_DIR` or `~/.pi/agent`) and refuses — naming each difference — when the model is missing or its cap, effort level or routing differ from the registry. The repo copy was tested; the installed copy, the one pi reads, was not.
