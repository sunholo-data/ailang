### Fixed — dev CI red since 2026-10-13 (three deterministic causes)

- **`test` / Check git exec sites**: `internal/executor/managed_agents/devapi_workspace.go`
  (gemini_agents, ffef3402a) ran bare-name `exec.CommandContext(ctx, "git", ...)`; both sites
  now go through `gitexec.CommandContext`, which resolves git to an absolute path. The gate
  baseline is unchanged.
- **Build windows-latest / Run tests**: `TestPlanWorkspace_LocalDeltaCoversEverythingAndSparesIndex`
  and `TestDevAPI_ExecuteRoundTrip` compared exact bytes in temp repos that inherited the
  runner's global `core.autocrlf=true`, so files came back with CRLF. The fixture repo and its
  clone now pin `core.autocrlf=false`.
- **Docs build**: `tools/gen-env-docs` escaped `<`/`>` but not `{`/`}`, so the
  `AILANG_OPENROUTER_PROVIDER` doc (`'{"sort":"throughput"}'`, 50fa27357) was parsed as an MDX
  expression and the whole Docusaurus build failed. The cell escaper now spells out
  `< > { }` outside code spans and leaves code spans literal (which also stops
  `GET /api/approvals/<id>` rendering as `&lt;id&gt;`). Regenerated `env-vars.md`.
