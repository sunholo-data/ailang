### Changed — docs follow the v1.0 bar v3 re-cut (D-64) (2026-11-09)

The v1.0 bar was re-cut on 2026-11-09 to bar v3, "1.0 = a promise we can keep" (ledger D-64 in
`design_docs/v1-mission.md`). The gates are now the stability promise, zero open P0s, packages and
the cloud executor MCP in the promise, and simplification Phase 5. Fleet-tier pass rates and
cost-per-verified-success are published at release and no longer gate it. Living docs that still
described the bar v2 gates now say this:

- `docs/VISION.md`, `docs/docs/why-ailang.mdx`, the generated roadmap page (via
  `docs/scripts/sync-design-docs.sh`) and `design_docs/PROGRAM.md` §8 describe the v3 gates with no
  date. The platform work (M-AGENT, M-ENTROPY, M-CSP, effect refinement) is listed as v1.1, and
  `ailang messages` is described as Experimental, not Stable.
- `docs/docs/intro.mdx` says the stability promise also covers packages and the hosted MCP tools.
- `m-fable-strategy-review` notes that its R1–R7 → bar-v2 clause mapping was superseded by D-64.
  The R-items remain ordinary roadmap work. `m-v1-simplification-program` now records Phases 0–3
  as done, Phase 5 as gate G5 and Phase 4 as optional.
- Design docs re-scored by D-64 moved to `design_docs/planned/v1_1_0/`:
  m-effect-clock-net-fs-modes, m-serve-api-live-tool-registry, m-agent-step-cancellation,
  m-contract-verification-coverage, m-verify-bounded-unrolling-false-counterexample and
  m-cohort-manifest-build-provenance. m-effect-refinement, m-effect-scope-params and
  m-dialect-keyword-diagnostics went with them.
- Docs for work that already landed moved to `design_docs/implemented/<release>/`:
  m-bytecode-pattern-arity-fix (v0.33.1), m-mission-slot-heartbeat (v0.35.0), the
  m-effect-replay-subsumption sprint plan (v0.30.0) and three nightly-classifier sprint plans
  (v0.31.0 and v0.32.0). Every link to a moved doc was updated, and so were the links inside the
  moved docs. Some links to these docs were already broken (e.g. `../v1_0_0/m-effect-refinement.md`
  from `implemented/`), and those were fixed too.
- `docs/LIMITATIONS.md` and `docs/docs/reference/limitations.md` no longer link to
  `planned/v1_0_0/m-v1-stability-promise.md`, a path that does not exist. The doc has been in
  `implemented/v0_29_0/` since v0.29.0.
