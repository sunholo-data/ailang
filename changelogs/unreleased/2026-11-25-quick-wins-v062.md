### Ergonomics & Tooling Polish
- **Multi-hole reporting (`TC_HOLE`)**: `ailang check --json` and `--format=agent` now report **all** typed holes (`_?`, `?name`) in a module in a single pass instead of stopping at the first hole.
- **Smarter `ailang check --fix`**:
  - Auto-fixes the `PAR017` `= {` trap (`func f() -> T = { ... }` → `func f() -> T { ... }`).
  - Auto-appends missing stdlib symbols (like `map` or `filter`) when exactly one exporting stdlib module is already imported in the file.
- **Stdlib additions**:
  - `std/map.getOrElse[k, v](m: Map[k, v], key: k, default: v) -> v` (O(1) default lookup).
  - `std/result.toOption[a, e](r: Result[a, e]) -> Option[a]` and `std/result.fromOption[a, e](opt: Option[a], err: e) -> Result[a, e]`.
