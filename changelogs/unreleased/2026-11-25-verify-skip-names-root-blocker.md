### Changed — verify: a skip through helpers names the construct that blocks it

- **Skips reached through helper functions now end with the real blocker** (M-VERIFY-SOUNDNESS-COVERAGE). When a helper's body did not encode, the callee resolver dropped the error, and the caller reported only `calls user function "mid" that is not SMT-encodable in this context`, without saying why. The resolver now records why each helper was not defined, and the message carries that reason down the chain: `calls user function "mid" that is not SMT-encodable in this context: calls user function "leaf" that is not SMT-encodable in this context: … match on list patterns (x :: rest) is outside the decodable fragment`. No status changes; only the reason text grows.
- **`tools/verify-gap-map` ranks skips by root blocker.** A new "Skips by root blocker" table strips the encoder's layers off each skip reason (`let body:`, `callee "X":`, `the specialised map chain does not encode:`, the helper chain, …) and splits a list of rejections. Each blocker is counted twice: `any` is the number of skips it appears in, and `sole` is the number it alone blocks. Each banked row records its `blockers`, taken from the untruncated reason.
