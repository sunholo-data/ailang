### Changed — cloud-setup skill targets the current Claude Code cloud container

The 2025 skill pinned Go 1.24 with `GOTOOLCHAIN=local` (a hard error against today's `go.mod`), rewrote DNS and disabled TLS checks with `wget --no-check-certificate`. The rewrite documents the environment config the user enters once (Full network; `AILANG_STORAGE_MESSAGING=gcp`, `AILANG_MESSAGES_PROJECT`, `AILANG_AUTOPUSH=0`; a least-privilege `GCP_SA_KEY_JSON` secret). `setup.sh` is now idempotent and never fails the boot: it writes the key to the ADC path, apt-installs z3, runs `make quick-install` and links `/usr/local/bin/ailang`. `verify.sh` checks the message-plane env, and no longer trusts `gcloud auth print-access-token`, which succeeds on the harness's placeholder token while every API call fails.
