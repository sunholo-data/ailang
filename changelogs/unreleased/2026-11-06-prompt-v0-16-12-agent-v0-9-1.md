### Fixed — teaching prompt v0.16.12 and agent prompt v0.9.1 correct verified mistakes

Found while writing the canonical examples in `examples/runnable/stdlib/`. Every claim below was
checked against the binary before the edit. v0.16.11 is frozen; v0.16.12 is active.

- **Teaching prompt v0.16.12:**
  - **Blocks:** one `let` per line is the canonical form (what `ailang fmt` writes); `;` is still
    accepted. The one place `;` is required is when a block's final expression starts with `{`.
  - **`**`:** removed from the operators table (it does not parse); use `pow`.
  - **`print`:** the stdlib section no longer claims it is auto-imported. Only `println` is;
    `print` needs `import std/io (print)`. The ADT, Option, state-machine and JSON examples now
    use `println`.
  - **`mapSlicesJoin`:** stated to join with no separator.
  - **JWT:** the section shows `verifyWithKid(token, keysJson)` and field access on `decodeJWT`'s
    record.
  - **Record patterns:** must name every field or end with `...`.
  - **std/zip:** the example and import line use the public API instead of internal `_zip_*`
    builtins; likewise `std/xml` instead of `_xml_*`.
  - **Common Mistakes** gains rows for `x = …`, `**`, int `max`/`min`, non-exhaustive matches
    (not caught by `ailang check`) and partial record patterns.
- **Agent prompt v0.9.1:**
  - `print`, `readLine` and `getArgs` are no longer listed as prelude.
  - `int_to_float` and `float_to_int` (which do not exist) are replaced by
    `std/math (intToFloat, floatToInt)`.
