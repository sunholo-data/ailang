### Changed — packages: measured change classes, contracts in signatures, atomic lock writes, nested packages (M-PKG-PARALLEL-AGENTS Sprint 1)

Phase 1 of [M-PKG-PARALLEL-AGENTS](../../design_docs/planned/v0_63_0/m-pkg-parallel-agents.md): packages as the unit of parallel agent work.

- **Atomic `ailang.lock` writes.** `LockFile.Save` wrote with a plain `os.WriteFile`, so agents sharing a checkout read truncated locks: 16 of ~9,700 concurrent runs failed with `unexpected end of JSON input`. It now writes a temp file in the same directory, fsyncs it and renames it over the lock. The same 45-second concurrency run against the fixed binary: ~5,000 runs, 0 failures.
- **Contracts are part of the v2 signature set.** Each exported function's `requires`/`ensures` are recorded in its interface (`"contracts"` in `ailang iface`, in source order) and enter the signature set as `<module>:contract:<fn>:<clause>` lines, plus one `meta:contracts:v1` marker. They are kept out of `interface_hash_v2`: ailang-parse's v2 hash is byte-identical before and after (618 → 704 signatures). The compile cache key moved to v14 so cached interfaces cannot drop contracts. The stdlib goldens for `std/audio` and `std/string` were refrozen (they gain `contracts` arrays only).
- **Change classes are measured at publish.** The cascade envelope and the dependents' upgrade message now classify from the previous version's banked `interface_signatures` and the new set. Additions are class B and take the deterministic cascade path; before, any in-module addition was C and went to AI. Any contract change is C, even under an equal interface hash. A pair where one side predates the marker is U (review). `affected_exports` names the removed or changed signatures. Pairs with no signatures on either side keep the old heuristic.
- **`PUB025`: `[release] kind` versus the measured class.** `pkg quality` and `publish` measure against the previous published version (`release.measured_class` / `measured_against`). `fix`, `security` or `feature` over a measured C warns, and gates from v0.64.0; `breaking` over a measured A is informational.
- **A nested `ailang.toml` is a package boundary.** Source discovery, `check`, the content hash, the publish staging copy, the tarball and the stale-test-body scan all skip directories that hold their own manifest. Before, a nested package was compiled into the outer one (MOD010 on its module paths) and shipped in its tarball.
- **`ailang pkg docs` prints canonical import lines** (`import pkg/<vendor>/<name>/...`) after the AGENT.md, one per exported module.
