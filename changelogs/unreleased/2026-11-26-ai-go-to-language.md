### Added — M-AI-GO-TO-LANGUAGE: `deriving (Json)`, `let x = expr?`, `check --fix` Phase 2, `ailang inspect`, and stdlib scripting batteries

- **`deriving (Json)` for Records & Sum ADTs (Slice 1, D1=a)**: Monomorphic record and algebraic sum types with `deriving (Json)` (or `deriving (Eq, Json)`) now synthesize pure `encode<Type>(v: <Type>) -> Json` and `decode<Type>(j: Json) -> Result[<Type>, string]` functions (exported iff the type is exported). `Option[T]` record fields omit the key on `None` and accept both missing keys and `null` on decode; sum ADTs encode with `"tag"` plus `"fields"` (positional) or named keys; polymorphic types emit `TC_DERIVE_JSON_POLY`.
- **`let`-bound `?` Error/Option Propagation (Slice 2, D2=a)**: `let x = expr?` (and pattern/typed forms like `let (a, b) = expr?`) now unwrap `Result[T, E]` (`Ok`/`Err`) and `Option[T]` (`Some`/`None`) along a function's return spine with early return on `Err`/`None`, desugaring cleanly at the surface-AST level with 0 bytecode VM fallbacks. Non-`let` sub-expression `?` emits `PAR_TRY_LET_ONLY` with a hoist hint; non-spine usage emits `TC_TRY_NON_SPINE`.
- **`ailang check --fix` & LSP `codeAction` Phase 2 (Slice 3, D3=a)**: Expanded `internal/quickfix/` and `internal/lsp/` to automatically stamp missing `! {Effects}` onto function signatures (merging existing rows while preserving `@limit=N`/`@min=N`/params and stripping contradictory `pure `) and rewrite `s1 ++ s2` on string operands to `"${s1}${s2}"` interpolation with adjacent literal inlining.
- **`ailang inspect` Semantic Module X-Ray (Slice 4, D4=a)**: Added `ailang inspect <file-or-dir>` (`--format=agent` default, `--json`, `--exports-only`, `--relax-modules`) to emit a compact `<100ms` 1-line-per-symbol summary of types, deriving clauses, exported and local functions, resolved signatures, `! {Effects}`, `requires`/`ensures` contracts, line numbers, and direct callees.
- **`std/string` & `std/fs` Scripting Batteries (Slice 5)**: Added `indexOf`, `stripPrefix`, `stripSuffix`, `padLeft`, `padRight`, `lines`, and `unlines` to `std/string` and `readLines`, `writeLines`, `readLinesResult`, and `writeLinesResult` to `std/fs`, with updated `.stdlib-golden/` snapshots and runnable/unit tests.
