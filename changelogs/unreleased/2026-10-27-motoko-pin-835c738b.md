### Fixed — motoko path guard: symlink escape through a newline-named link

- The carried path guard walked paths with `$(dirname …)`, which drops trailing newlines. A `WriteFile` through a symlink named `nl\n` could therefore create a file outside the workdir.
- The pin now carries the reviewed upstream PR #234: the walk uses parameter expansion, and one guard script is kept equal across `tool_runtime` and `ailang_tools`.
