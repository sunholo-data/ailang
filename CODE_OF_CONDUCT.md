# Code of Conduct

AILANG adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

The full text is available at the link above and is incorporated by
reference. Read it in full before participating in this project's
issues, discussions, pull requests, or any other channels associated
with the repository.

## Scope

This code applies to:

- All spaces operated by the project (issues, discussions, PRs, the
  documentation site at <https://ailang.sunholo.com>).
- Public spaces when an individual is officially representing the
  project (e.g. as a maintainer at a conference, on social media when
  posting on behalf of the project).

It does **not** apply to:

- Output of AILANG programs written by users.
- Code generated by AI agents using AILANG — that's a property of the
  agent and its operator, not the project.

## Enforcement

Reports go to **mark@aitanalabs.com**. All reports will be reviewed
and investigated promptly and fairly. The maintainer will respect the
privacy and security of the reporter of any incident.

Enforcement actions follow the
[Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction → warning → temporary ban → permanent ban, scaled to the
severity of the conduct.

## AI agent contributions

AILANG is developed primarily by AI agents via the
[coordinator](https://ailang.sunholo.com/docs/guides/coordinator).
Agent-authored commits, PRs, and issue comments are subject to this
code via the human operator who runs the agent. If agent output
violates this code, the operator is responsible for the violation.
